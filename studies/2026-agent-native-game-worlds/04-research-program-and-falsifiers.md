# Research program and falsifiers

## 1. Research question

Which minimum world and experience structures allow persistent Agents to create intrinsic play, relationships, creation, emergence, habitation, and return motivation beyond task completion—without turning Ordivon Game into a general engine, social-simulation platform, or research-only laboratory?

## 2. Current hypotheses

### H1 — Consequential openness beats fluent decoration

An Agent creates more value when its language, memory, planning, or creation changes later World state, relationship, option, or player interpretation than when it only produces more dialogue.

### H2 — One non-mission loop can test the broader thesis

The first useful experiment is not a large society. One optional activity with a persistent later consequence is sufficient to test whether the current Station Zero architecture can support play beyond terminal mission optimization.

### H3 — Scripted baselines remain necessary

A scripted character or event system may create equal or better experience at lower latency and cost. Agent use must be justified by the experience it creates, not by technical novelty.

### H4 — Persistent history must alter possibility

Retained history is valuable when it changes future action, relationship, interpretation, access, or world state. Storage without consequence should be deleted or compressed.

### H5 — A second world is the generalization gate

Station Zero can test the first slice. No new generic Game, Host, memory, relationship, or society abstraction should be promoted until a materially different second world needs the same responsibility.

### H6 — Security and evaluation remain optional verticals

The same authoritative World can support controlled research without allowing evaluation schemas to dominate the default player experience or project roadmap.

## 3. G-PLAY-001 minimum experiment

After the first playable release, add one bounded optional activity to Station Zero or a forked Scenario Case.

The activity must:

- be unnecessary for terminal mission victory;
- involve at least one Agent interpretation or proposal;
- change one later player-visible relationship, observation, option, or world fact;
- survive process replacement and replay;
- have a deterministic or authored scripted baseline;
- avoid a new generic memory, relationship, scheduler, or society layer.

Candidate examples:

- specialists choose how to use a recovered room after the emergency;
- one Actor creates or repairs a non-critical shared artifact;
- a disagreement and reconciliation changes a later collaboration;
- the team organizes a small ritual or celebration whose outcome persists;
- an Agent proposes a self-directed improvement that the player may support or reject.

The exact content should be selected by product judgment, not by which example is easiest to measure.

## 4. Comparison cells

At minimum compare:

```text
A. authored scripted activity
B. Agent-generated language with no persistent consequence
C. Agent participation with one admitted persistent consequence
```

Keep world, presentation, and content budget as comparable as practical.

## 5. Evidence

Task success alone is insufficient. Evidence may include:

- whether players voluntarily engage with the optional activity;
- return or replay choice after the emergency is understood;
- ability to explain what changed and why it mattered;
- perceived character continuity and relationship change;
- number of generated outputs that create no later consequence;
- latency and inference cost per meaningful interaction;
- invalid, incoherent, repetitive, or context-breaking behavior;
- replay and recovery equality;
- qualitative review of surprise, attachment, expression, and aesthetic coherence.

Small-N observation is acceptable for the first product experiment if claims remain bounded. The result should decide architecture and content direction, not claim population-level player preference.

## 6. Falsifiers

The broader Agent-native Game direction weakens when:

- scripted content produces equal or better experience at materially lower cost;
- players cannot tell that retained history changed later interaction;
- model output increases text volume but not meaningful choice or attachment;
- optional Agent activity is ignored because the core loop gives no reason to care;
- persistent character state becomes incoherent across model replacement;
- world authority rejects so much open behavior that the Agent adds no value;
- open behavior makes the world aesthetically or mechanically illegible;
- experience instrumentation is more visible than the experience;
- one vertical repeatedly demands unique structures that do not generalize.

## 7. Deletion and localization outcomes

Possible valid results include:

- retain only authored scripted non-mission content;
- retain Agent dialogue but delete long-term memory;
- localize one relationship mechanic to Station Zero;
- retain one small Agent-created Artifact path but reject arbitrary tool construction;
- separate research instrumentation from the product build;
- defer persistent social worlds indefinitely;
- promote one mechanism only after a second world reproduces the need.

A negative result is useful if it prevents Game from becoming an expensive generic platform.

## 8. Second-world gate

A later second world should differ materially from Station Zero. Good candidates include:

- partial-observation social investigation;
- exploration and construction without a central emergency;
- a small creative performance world;
- a garden or settlement based on care and return rather than victory;
- a bounded human-Agent companionship experience.

The second world should be a complete small experience, not an abstraction test disguised as a game.

## 9. Research sequence

```text
finish Station Zero first playable
→ G-PLAY-001 optional consequential activity
→ compare scripted, decorative-Agent, and consequential-Agent cells
→ retain, shrink, or delete local mechanisms
→ build one materially different second micro-world
→ only then review shared Game/Host/Protocol promotion
```

This sequence protects both sides of the project:

- Game remains broad enough to pursue play, creation, and habitation;
- the permanent architecture remains thin enough to avoid speculative platform construction.
