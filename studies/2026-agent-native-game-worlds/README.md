# Agent-native game worlds: play, creation, habitation, and research

> **Status:** completed reference study. `ANC-GAME-002` is deferred; Station Zero product evidence must precede any generic world-platform construction.

## Purpose

This study corrects an overly instrumental interpretation of Ordivon Game.

A deterministic Game World with replay, hidden truth, multi-Agent coordination, and independent verification is valuable for Host, Harness, evaluation, and Security research. That does not imply that research utility is the definition of Game.

The broader thesis is:

> Ordivon Game may create open interactive worlds in which people and Agents play, explore, create, cooperate, compete, form relationships, produce histories, and sometimes exist without a productivity objective.

```text
Game
= World
+ Play
+ Agency
+ Creation
+ Emergence
+ Experience
```

Research and Security are legitimate consumers of these worlds. They are not the universal owner of their meaning.

## Result

This study creates `ANC-GAME-002` as a distinct question from the completed Game/Host convergence question.

- `ANC-GAME-001` asks which Agent-era responsibilities belong in Game versus one reusable Host.
- `ANC-GAME-002` asks which world and experience structures create intrinsic play, creation, relationship, habitation, and return value beyond task completion.

The new question is intentionally not an active platform program. Station Zero's first playable remains the immediate product priority. The first post-alpha test should be one small non-mission activity with a persistent consequence, compared against a scripted baseline—not a general social simulator or civilization engine.
