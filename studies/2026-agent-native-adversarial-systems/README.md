# Agent-Native Strategic Adversarial Systems

Status: deferred reference after Round 1; `research/portfolio.json` owns any reactivation

## Purpose

This study reorients Ordivon Security from a containment/evidence-centered
security laboratory toward a research program on **strategic adversarial
agency**.

The project is not asking how to build another security platform. It asks:

> What changes when an intelligent opponent actively shapes an Agent's
> observations, beliefs, actions, organization, resources, and learning?

## Core conclusion

Classical security and current autonomous-cyber research already provide:

- detailed attack and defense vocabularies;
- mature execution, isolation, observation, and recovery mechanisms;
- automated vulnerability discovery, proof, exploitation, and patching;
- partially observed Red/Blue environments and learned policies;
- Agent evaluation, sabotage tasks, monitors, and control protocols;
- game-theoretic and MARL models for multi-actor uncertainty.

The remaining candidate Ordivon layer is not another implementation of those
mechanisms. It is the still-immature layer for:

```text
strategic objectives
+ Campaign synthesis and revision
+ opponent models and belief state
+ deception and counter-deception
+ initiative, tempo, exposure, and strategic resources
+ multi-Agent adversarial organization
+ attack-defense coevolution
+ evaluation against actors that study the evaluator
```

## Project implication

The current `ordivon-security` Campaign Manifest, lifecycle ledger, evidence
bundle, residual closure, and Link/Edge/Runtime composition are useful
experimental infrastructure. They are not the project's intellectual center and
should remain frozen until a dynamic-opponent experiment exposes a concrete
missing responsibility.

Research should advance first through mature simulated and evaluation
substrates. A custom persistent network-attached range is a later fidelity
upgrade, not a prerequisite for understanding strategic opposition.

## Claim boundary

This study does not claim that Ordivon has implemented strategic adversarial
Agents. It does not claim novelty for any proposed concept. It does not authorize
real-world offensive activity. It identifies a research gap and a program for
determining whether Ordivon should construct anything in that gap.
