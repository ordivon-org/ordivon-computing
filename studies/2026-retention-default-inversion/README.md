# Retention Default Inversion

This study records a change in Ordivon's audit posture discovered through the 2026-08-02 Station Zero product and source review:

> Historical existence does not grant active legitimacy. When an existing structure is re-audited, removal from the active path is the default disposition; continued retention is an affirmative, time-bounded judgment that must prove current value.

The change sharpens rather than replaces Core A11. New durable constraints already carried a high admission burden. The missing rule was that old constraints, compatibility paths, tests, documents, protocols, and governance mechanisms must periodically re-enter under the same burden instead of inheriting legitimacy from prior implementation.
