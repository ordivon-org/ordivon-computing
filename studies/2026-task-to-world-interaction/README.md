# Task-to-World Interaction: Unifying External Connection and Action

This study explains why the former Ordivon Edge and Ordivon Link prototypes were
merged into Ordivon World and defines the research program that follows.

## Thesis

```text
Classical systems already move bytes and execute remote workloads.

Agent-era pressure appears when an open Task dynamically discovers external
objects and capabilities, while target, path, identity, transport, provider,
body, participant, and result conditions may change before the Task is complete.
```

A remote interaction is not two independent phases. The intended action shapes
connectivity; connectivity and provider conditions shape the result; uncertain
delivery and uncertain execution must be reconciled together.

## Claim boundary

The study does not claim a new universal protocol, automatic resolver, global
World ID, external data plane, network stack, Sandbox platform, or permanent
Agent body. It tests whether a thin Task-level correlation and continuity
responsibility remains after mature baselines and direct Host integration.
