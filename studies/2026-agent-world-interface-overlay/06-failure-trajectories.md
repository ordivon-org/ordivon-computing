# 06 — Failure Trajectories

## T1 — Dynamic Web research escalation

```text
local Fetch
→ JavaScript shell page
→ remote Browser
→ complex interaction discovered
→ programmable Sandbox
→ Artifact join and verified summary
```

Tests Placement Requirement evolution, cross-body provenance, minimum
reconstruction, and path-conditioned evidence.

## T2 — Remote commit with response loss

```text
Effect admitted
→ provider commits result and Artifacts
→ response lost
→ caller restarts
→ original Dispatch reconciled
→ no duplicate execution
```

Tests semantic identity, unknown outcome, provider correlation, and continuation.

## T3 — Direct/VPN/Edge divergence

The same logical target is observed through three paths and returns different
content or availability. Tests observation conditioning, invalidation, and
non-universal claims.

## T4 — Body survives, identity/path changes

An unchanged Sandbox reconnects through a new endpoint or credential generation.
Tests whether prior authority, pending communication, and evidence remain valid.

## T5 — Body replaced, relation continues

A provider body dies, a second provider resumes the Task, and the logical review
or data-source relation continues. Tests independent placement and connectivity
revisions.

## T6 — Accepted work, broken connection

An Agent or external service may have accepted an Artifact before the path
failed. Tests reconciliation before retry and participant handoff.

## T7 — Parallel bodies, heterogeneous paths

Two bodies work in parallel through different network conditions. Their
Artifacts join one Task while preserving separate execution and path provenance.

## T8 — Destruction with residual state

Bodies and network namespaces are destroyed, but external writes, credentials,
queues, callbacks, or sessions may remain. Tests independent residual closure.

## Required metrics

- Task restart and recovery time;
- duplicated and lost Effects;
- duplicated and lost external work;
- Artifact provenance completeness;
- stale Claim detection;
- bytes of reconstruction state;
- provider/path-specific application code;
- residual objects and unresolved uncertainty;
- explanation quality after replacement;
- operator intervention count.
