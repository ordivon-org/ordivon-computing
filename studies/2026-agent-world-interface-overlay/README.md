# Agent World Interfaces: Placement, Connectivity, and Continuity

This study re-derives Ordivon Edge and Ordivon Link from the classical execution
and networking stacks instead of treating existing repository objects as
permanent architecture.

## Thesis

```text
Classical systems already create bodies and move bytes.

Agent-era pressure appears when open Tasks dynamically discover where to act
and whom to connect, while bodies, providers, paths, endpoints, identities, and
responses may change before the Task is complete.
```

The candidate Agent-native contribution is therefore an overlay:

```text
Task / Attempt / Effect
→ semantic requirement
→ versioned binding to mature infrastructure
→ physical execution or communication
→ Receipt / Artifact / Observation
→ verification, invalidation, reconciliation
→ continued Task
```

## Reading rule

Every proposed object is classified as one of:

- **classical substrate** — inherit and adapt;
- **provider-specific adapter** — keep local to one integration;
- **research hypothesis** — test before standardization;
- **cross-workload responsibility** — candidate for stable Ordivon ownership;
- **unnecessary duplication** — delete or archive.

Current Edge Node and Link Network World abstractions begin this study as
research hypotheses, not conclusions.
