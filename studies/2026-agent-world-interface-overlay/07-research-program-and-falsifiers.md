# 07 — Research Program and Falsifiers

## Phase A — Classical authority maps

Produce exact responsibility maps for:

- process/container/VM/browser/Sandbox/provider lifecycle;
- schedulers and durable workflow engines;
- DNS/CNI/VPN/proxy/service mesh/workload identity/messaging;
- receipts, operation polling, traces, and provenance.

Output: what is solved, amplified, composed, rewritten, or unowned.

## Phase B — Current repository truth audit

Classify every Edge and Link component as:

- production provider or operator capability;
- observation/evidence producer;
- classical reference mechanism;
- research hypothesis;
- duplicated or inactive scope.

Do not rename code to simulate architectural progress.

## Phase C — Two vertical Host workloads

1. Dynamic Web research using local Fetch, remote Browser, and programmable
   Sandbox escalation.
2. Agent-to-Agent or service review using Artifact handoff, response loss,
   identity rotation, path replacement, and explicit handoff.

Use direct integrations as controls.

## Phase D — Field minimization

Start from complete evidence, then delete fields one at a time. Retain only
fields whose removal causes attribution, recovery, safety, cost, or explanation
failure across both workloads.

## Phase E — Boundary decision

For each candidate:

- promote to stable cross-workload contract;
- keep as research vocabulary;
- absorb into Host or provider adapter;
- freeze as reference experiment;
- archive or delete.

## Global falsifier

The World Interface overlay is not an independent Ordivon layer if direct Host
integration with mature providers and network systems achieves equal continuity,
uncertainty handling, evidence validity, replacement, and operator clarity with
less permanent machinery.

## Anti-roadmap

Until the experiments produce evidence, do not:

- build a general Sandbox, VM, container, scheduler, VPN, CNI, proxy, mesh,
  transport, or identity platform;
- implement automatic provider or route selection;
- standardize Placement or Connectivity schemas;
- create a global World ID;
- merge Edge and Link repositories;
- expand local-unshare or Network World into production infrastructure;
- claim persistent Agent embodiment or network-native intelligence.
