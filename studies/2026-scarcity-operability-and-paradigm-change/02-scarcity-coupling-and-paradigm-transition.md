# Scarcity, Coupling, and Paradigm Transition

## 1. How a local adaptation becomes a universal-looking rule

A recurring historical process is:

```text
scarce resource or expensive failure
→ locally rational adaptation
→ repeated institution and professional norm
→ concept treated as natural or universal
→ original cost structure changes
→ the norm persists as a conceptual fossil
```

The term `conceptual fossil` does not mean useless. It means that the rule's current justification must be separated from the environment that originally produced it.

## 2. Scarcity creates couplings

When a resource is scarce, several functions are often forced into one object or role.

### Knowledge and memory

```text
knowing
≈ personally remembering
≈ controlling access to a scarce source
```

Cheap retrieval and model synthesis separate:

```text
memory
knowledge access
source evaluation
judgment
application
```

### Implementation and asset value

```text
expensive implementation
≈ durable asset
≈ something that must be protected from change
```

Cheap regeneration and recoverable branches separate:

```text
code
learned judgment
validated behavior
interface commitment
unique operational state
```

The code may be replaceable while the evidence, contract, or decision remains valuable.

### Research and publication

```text
research result
≈ paper
≈ final successful route
```

Persistent Agent-assisted work can separate:

```text
research state
publication view
formal certificate
experimental evidence
open branches
attribution record
```

### Safety and prevention

```text
safety
≈ preventing action before it occurs
```

Isolation, observation, rollback, reconciliation, and compensation can separate:

```text
reversible internal exploration
external commitment
irreversible consequence
recovery obligation
```

This is the basis of Ordivon's wide-interior and narrow-consequence-boundary principle [R01] [R02].

## 3. Productive capability performs conceptual analysis

A concept often appears indivisible because its components cannot be operated independently. When tools make separate control possible, the concept can split.

This is not merely linguistic clarification. It is practical decomposition:

```text
new control surface
→ independent intervention
→ independent measurement
→ new abstraction boundary
```

Examples:

- version control separates experimentation from permanent loss;
- containers and reproducible environments separate local trials from machine-wide mutation;
- Agent Harnesses separate model capability from long-horizon state and Tool use [O03];
- formal proof systems separate logical validity from persuasive prose;
- automated evaluators separate candidate generation from immediate human review [G01].

## 4. Bottlenecks migrate rather than vanish

A simple production chain can be represented as:

```text
T ≈ max(T_generation, T_validation, T_execution, T_integration)
```

If generation time falls sharply, total throughput may become dominated by validation, execution, or integration. The system can even degrade if candidate volume grows faster than validation capacity.

The practical consequences include:

- more plausible errors in absolute terms;
- reviewer overload;
- duplicated rewrites and fragmented stewardship [O02];
- evaluator gaming;
- attention consumed by low-value branches;
- premature promotion of generated claims into durable knowledge.

The correct response is not to restore generation scarcity artificially. It is to redesign the pipeline around the new bottleneck.

## 5. Old structures become conditional tools

A paradigm transition does not prove that old forms must disappear.

Linear plans remain useful when:

- the path is known;
- dependencies are strict;
- parallel search has little value;
- the cost of deviation is high.

Hierarchies remain useful when:

- legal authority is concentrated;
- synchronized response is required;
- consequence ownership must be unambiguous.

Pre-commit review remains useful when:

- the action is difficult to reverse;
- external parties bear the risk;
- evidence cannot be obtained after the effect.

The transition changes their epistemic status:

```text
universal default
→ conditional mechanism with an explicit cost model
```

## 6. A two-sided rule

The lens can be summarized by two symmetric warnings:

> Do not mistake the current scarcity condition for a fundamental law of the world.

> Do not mistake a local fall in cost for the disappearance of all constraints and consequences.

Both errors produce brittle systems. The first preserves obsolete friction. The second externalizes unmeasured loss.
