# Kimi Capability-Governance Case

Observed through: 2026-08-01

## Surface and legal structure

Kimi exposes consumer, agentic, and Open Platform API surfaces under separate
terms and privacy documents. Public materials observed include global consumer
Terms effective 2026-01-21, Open Platform privacy terms effective 2025-04-28,
and product-specific 2026 privacy revisions.

## API data and content review

Kimi's API data-security documentation states that API input and output are not
used to train or improve Kimi models and are used to fulfil the current request.
It also describes built-in content safety review that automatically detects and
filters prohibited content and returns an error response. Users who believe the
review is incorrect are directed to support with a request ID.

This creates a request-level intervention and support path, but the public page
does not disclose classifier thresholds, account aggregation, appeal independence,
or aggregate reversal statistics.

## Power assessment

Kimi's public API data commitment may reduce training-related dependence compared
with opt-out consumer services. It does not remove hosted-service dependence,
request filtering, account eligibility, regional law, or the Provider's ability
to change models and interfaces.

Kimi is therefore best treated as a hosted Provider with comparatively concise
public governance documentation, not as an ungoverned or open-weight system.
