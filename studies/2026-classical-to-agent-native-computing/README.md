# From Classical Computing to Agent-Native Responsibility

This study separates the mature deterministic substrate from the responsibilities that are introduced or structurally rewritten when probabilistic model cognition participates directly in a persistent action loop.

It records the derivation behind the current Ordivon Computer thesis. It is deliberately more critical and detailed than `core/`: historical mechanisms, counterexamples, source boundaries, project evidence, and falsifiers remain here so that the Core can stay small.

## Central distinction

```text
classical substrate
  owns processes, bytes, transactions, transport, isolation, and execution

Agent-native overlay
  owns the semantic path from open goal to candidate action,
  bounded authority, durable effect identity, evidence, and revised work
```

The overlay does not replace the substrate. It closes a loop above it:

```text
human purpose
→ selected context
→ probabilistic cognition
→ candidate proposal
→ deterministic admission
→ durable effect
→ classical execution
→ observation and evidence
→ verification
→ revised task state or human decision
```

## Reading rule

The chapters distinguish five outcomes:

- **unchanged** — the classical mechanism remains sufficient;
- **amplified** — Agent workloads increase scale or importance but not semantics;
- **composed** — a new product combines old mechanisms without creating a new layer;
- **rewritten** — a classical abstraction remains but its contract changes materially;
- **new responsibility** — no lower layer owns a necessary non-bypassable invariant.

Only the last two outcomes can justify an Agent-native Core abstraction.
