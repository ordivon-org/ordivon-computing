# Working Foundations

This file contains the smallest current foundations from which the project’s architecture and research direction can be regenerated. Explanations and derivations live in [`../knowledge/`](../knowledge/) and [`../studies/`](../studies/).

## A0 — Begin from current model reality

Transformer-family systems form the present operational baseline for foundation-model workloads. The stack evolves as new architectures, experiments, and real workloads reveal better abstractions.

## A1 — Models are cognitive engines

Models interpret, infer, plan, generate, compare, and revise. The wider computing stack turns these probabilistic cognitive capabilities into persistent work in the world.

## A2 — Intent becomes structured execution

Natural language opens goals and expresses meaning. Agent representations progressively lower goals into identities, tasks, capabilities, preconditions, effects, verification, and executable actions.

## A3 — Memory is a hierarchy

Parameters, KV state, conversation context, task working state, durable knowledge, artifacts, and external world state are distinct memory layers with different lifetimes, costs, identities, and access patterns.

## A4 — Effects are first-class computational objects

An external action carries a target, preconditions, capability, idempotent identity, result semantics, and verification path. These properties make action understandable across models, runtimes, tools, and time.

## A5 — Long-horizon work evolves through recovery

Agent work proceeds through attempts, interruption, partial progress, correction, checkpoints, compensation, resumption, and integration. Errors and friction expose missing semantics and create the next improvement signal.

## A6 — New semantics create new layers

A new layer is valuable when a stable abstraction creates leverage across many workloads. Existing operating systems, databases, networks, compilers, and accelerators remain the substrate on which new Agent semantics are constructed.

## A7 — Thin cores release broad potential

A small set of clear primitives for identity, state transition, capability, effect, evidence, and recovery can support many models, providers, interfaces, domains, and future architectures.

## A8 — Knowledge grows through evidence and construction

Claims evolve through literature, explicit reasoning, prototypes, failure traces, reproducible experiments, benchmarks, and sustained real use. Each form of evidence can update the knowledge base, research map, and eventually the core.

## A9 — Agent capability moves the scarce frontier

As code and information production become cheaper, greater value concentrates in selecting important questions, constructing useful abstractions, connecting to real systems, validating outcomes, preserving continuity, and discovering new possibilities.

## Research cycle

```text
observe
→ formulate
→ construct
→ run
→ learn from friction
→ revise
→ preserve
```

The core defines the current generative structure. It remains small enough to be loaded, challenged, and reconstructed as one coherent model.
