# Core

The Core contains the minimum current theory needed to regenerate the repository’s architecture and research direction.

- [`foundations.md`](foundations.md) — working foundations and the acceleration test for durable constraints;
- [`stack.md`](stack.md) — inherited classical substrate and Agent-native responsibility overlay for plural participants;
- [`primitives.md`](primitives.md) — classical backend objects, executable semantic primitives, Host-proven work objects, and explicit research candidates.

Detailed explanations belong in [`../knowledge/`](../knowledge/). Learning and derivation paths belong in [`../studies/`](../studies/). Open alternatives and experiments belong in [`../research/`](../research/).

A concept enters the Core only when it is compact, stable across model and provider change, not already owned by a mature lower layer, non-bypassable for a real failure class, generative across materially different workloads, and beneficial after its latency, operating friction, compatibility burden, cognitive compression, and concentration of control are counted.

The Core does not encode one intelligence form as the permanent owner of every future purpose. It distinguishes current legal and physical ownership from the longer-run system requirement to support identifiable participants, commitments, negotiation, responsibility, refusal, and exit. Inclusion does not imply that every object is already a shared production implementation; `primitives.md` labels evidence and responsibility boundaries explicitly.
