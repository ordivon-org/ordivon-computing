# Core

The Core contains the minimum current theory needed to regenerate the repository’s architecture and research direction.

- [`foundations.md`](foundations.md) — working foundations;
- [`stack.md`](stack.md) — fourteen vertical layers and five cross-cutting planes;
- [`primitives.md`](primitives.md) — executable Kernel primitives, backend objects, and clearly separated future Task-Runtime candidates.

Detailed explanations belong in [`../knowledge/`](../knowledge/). Learning and derivation paths belong in [`../studies/`](../studies/). Open alternatives and experiments belong in [`../research/`](../research/).

A concept enters the Core when repeated use shows that it is compact, stable, cross-project, and capable of generating many downstream decisions. Inclusion in the Core does not imply that every candidate object is already implemented; `primitives.md` labels executable guarantees and research candidates separately.
