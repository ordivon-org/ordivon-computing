# Research question

## Problem

State the real-world problem, affected actor, and current failure.

## Scope

Declare population, system, environment, and time boundary.

## Consequence

State what changes if the answer is wrong or unknown.

## Falsifier

Name the first observation that would reject or narrow the current framing.

## Evidence required

State the minimum evidence capable of changing the judgment.
