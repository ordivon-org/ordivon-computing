# World Model Assimilation Round 001

Status: accepted Computing synthesis over exact owner revisions. This record does not replace any owner-native project fact. Machine record: [`world-model-assimilation-round-001.json`](world-model-assimilation-round-001.json).

## Why this round exists

The first Agent-first Computing reform changed how Ordivon projects were built. Those projects then produced new evidence. This round closes the missing return edge: it asks which results merely changed local implementations and which results require the shared world model itself to change.

## Accepted shared changes

### A6 — Selected view, source state, and selection authority are different

Harness now has accepted evidence that an Agent can explicitly choose exact caller input for durable later use while Harness mechanically preserves provenance, exact bytes, recovery, and the predecessor selection. Finance independently compiles domain state into bounded model-visible context rather than treating repository or chat history as the authority.

```text
owner-native / durable source state
!=
one model-visible selected view
!=
authority to change that selection
```

No shared WorkingSet or Memory service follows from this result.

### A10 — Historical evidence is not current truth

Security AE2 shows two valid independent sensor observations may conflict while neither is world truth; later authoritative current observation can resolve the present property without rewriting the historical conflict. World W5-B independently shows historical embodiment/materialization does not prove current Presence. Finance point-in-time research separately distinguishes historical knowledge-time from current-state evaluation.

```text
historical evidence remains historical evidence
current truth requires current-enough owner-native evidence for the property
evidence conflict != multiple world truths
current resolution != deletion of historical conflict
```

### A13 — Shared mechanics are not shared semantics

World W5-D shows Resource, Message, Entity, and provider effects share a lower causal/reconciliation skeleton while retaining materially different semantics. Computing's earlier content-identity experiment reached the same pattern across Runtime, Finance, Security, Studio, and World: exact byte identity can converge without creating one shared storage or lifecycle authority.

```text
repeated mechanics
→ factor mechanically when useful

repeated semantics across different owners
→ only then consider shared contract
```

## Pressures intentionally not promoted

- **Fast inner loops versus slower external consequence.** Studio, Web, Security, and Finance now provide a strong candidate relation, but the cross-domain experiment is not yet complete.
- **Presence / discovery / reachability / relationship as decision-scoped relations.** World evidence is strong; a second unrelated long-lived protocol or physical consumer should pressure it before Core promotion.
- **Immutable candidate inputs and evaluator sovereignty.** Runtime and Security make this highly relevant to self-improvement, but an actual candidate evaluation must consume the path first.
- **Durable Goal history.** Host names the current absence explicitly; no failure has yet forced a shared Goal event stream.

## Rejected shortcuts

This round explicitly does **not** create a generic Memory service, Global Agent/Presence Registry, Trust/Reputation database, GenericInteraction object, or universal creative/aesthetic score.

## Return to projects

The output of a Computing synthesis is a bounded question, not a synchronized patch command. Harness, Finance, Security, World, Studio, and Web now have different falsifiers derived from the accepted model changes. Their next owner-native results return to Computing only when they expose a new distinction, contradiction, scope limit, deletion result, or repeated cross-project relation.
