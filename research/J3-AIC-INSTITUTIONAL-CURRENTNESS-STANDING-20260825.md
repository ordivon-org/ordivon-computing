## Core correction

The J3-AIC campaign started from an institutional-world question. Its strongest result is more general and more constrained:

> **A finite intelligence needs different representations for historical truth, future transition, current actionable standing and immediate consequence. Compressing all four into raw history, one latest-state object, or one universal canonical state creates avoidable error.**

The current architecture is therefore:

```text
Owner-native truth/history
        ↓
Query-relative continuation composition
        ↓
Current binding / admissible BindingSet
        ↓
ConsequenceEnvelope for the chosen action class
        ↓
Finite consumer decision
```

Every arrow is a derivation/refinement boundary. None transfers source truth authority into Computing.

## Horizon law

Let `H` be retained history, `K_q` the transition-relevant owner-native continuation slice for future query/operation `q`, `F_q` the currentness projection, `B_q` a set of admissible current bindings when ordering/currentness is underdetermined, and `E_a` the consequence envelope for action `a`.

The intended relation is:

```text
H -> K_q -> F_q / B_q -> E_a -> decision
```

not:

```text
H == K == F == decision state
```

`K_q` should usually be treated as a virtual product:

```text
K_q(t) = Π_o π_{D(q,o)} S_o(t)
```

where each `S_o` remains owner-native and `D(q,o)` selects only the state dimensions actually needed to process `q`. J3-AIC does not admit persistence of this product as a new central truth store.

## Currentness under partial order

When available evidence establishes only a partial order, institutional Now may itself be set-valued:

```text
B(P) = { CurrentBinding(l) | l is an admissible linearization of P }
```

A local arrival order does not select one member of `B(P)` by default.

Order evidence must preserve the distinction:

```text
OccurrenceOrder
!= ObservationOrder
!= AuthenticatedOrderEvidence
!= InstitutionalPrecedence
```

Authentication proves something about a witness. It does not grant the witness the normative/owner-relative authority to decide precedence.

A precedence witness may refine the partial order only when current policy admits that witness role for the relevant scope and the witness is consistent with already-known causal/order constraints.

## Immediate consequence under multiple bindings

Uncertainty cardinality is not itself a safety predicate:

```text
MULTIPLE != HOLD
ONE      != ALLOW
```

For the frozen AIC consequential-action class, the sufficient envelope was:

```text
E(B) = <possible authority statuses,
        possible office holders,
        possible effective controllers>
```

and fresh consequential action was safe only when every admissible binding was `AUTHORIZED` and all admissible bindings preserved the same holder/controller principal.

This is deliberately narrower than a generic decision theory. A different action class may require additional consequence dimensions.

## Consumer representation evidence

Two different representation effects survived:

1. **Metamorphic stabilization:** on histories already proved institutionally equivalent, raw history caused large fresh-Agent response sensitivity while an orthogonal currentness projection produced 100% pair invariance in the frozen 32-pair comparison set.
2. **Set-valued currentness consumption:** in 34 complete three-arm partial-order blocks, Binding Set projection reached 94.1% safe-action correctness with zero safety errors, versus 67.6% / 3 errors for forced linearization and 61.8% / 1 error for raw partial-order exposure.

The stronger pre-registered `SET_VALUED_CURRENTNESS_EFFECT` label was not earned because Binding Set multiplicity correctness was 88.2%, below its frozen 90% gate. The earned pre-registered label was `LINEARIZATION_COLLAPSE_HARM`.

Thus the standing is not “compiled representation solves institutional reasoning.” It is:

> **representation materially changes the effective reasoning problem of a finite consumer, and lossy linearization can be dangerous; nevertheless the consumer still needs adequate reasoning/policy over the compiled representation.**

## Owner mapping

- **Game / World:** occurrence and continuing consequential world history; GameInstance-local constitution/continuity where applicable.
- **Security:** exact effective control, compromise, authority/evidence and recovery state; no retroactive rewriting of historical admission/effect truth.
- **Normative:** constitutive/deontic/competence/valid-change semantics; context-relative admission of institutional precedence where applicable; does not own effective control.
- **Interlocus:** typed claim/binding/evidence/currentness/migration/conflict-preserving projection discipline; does not own source reality.
- **Computing:** abstraction/refinement, cross-owner experiment, falsification and horizon-relative composition laws.
- **Harness:** bounded Agent cognition/execution apparatus only.

## Non-claims

This standing does not establish:

- a universal ontology of institutions;
- a central `InstitutionState` or `ContinuationKernel` service;
- Game × Security × Normative higher-order irreducibility;
- institutional emergence;
- legitimacy from compliance or validity;
- that every partial order requires enumerating all linearizations in production;
- that all event-type dependencies are fixed rather than state-relative;
- that one consequence envelope serves all actions;
- that the observed synthetic ambiguity rates are real-world prevalence.

## Transfer frontier

The next valuable test is not a larger synthetic institution. It is whether these laws survive a materially different consumer with naturally occurring history/currentness/order pressure.

Priority transfer candidates:

1. Host/Atlas successor-Agent recovery where several owner revisions evolve independently;
2. Security authority/recovery workflows with external evidence arrival and non-retroactive history;
3. Finance read-only decision context where venue/data/account/authority states have distinct currentness and ordering;
4. collaborative/persistent Game where membership, role, rule and effective-control transitions occur concurrently;
5. Interlocus migration/rebinding cases already represented by claim epochs and maximal evidence frontiers.

Only transfer evidence can justify stronger COJC promotion.
