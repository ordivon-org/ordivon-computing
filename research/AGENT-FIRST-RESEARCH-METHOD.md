# Agent-First Research Method

The machine authority for this method is [`research-method-v1.json`](research-method-v1.json). This document explains one **specialized research method for responsibility externalization**; it does not define the whole Ordivon world-model loop, own portfolio status, Trial validity, product state, or deployment authority. Cross-project world-model revision is governed separately by [`world-model-loop-v1.json`](world-model-loop-v1.json).

## Research question

Ordivon research no longer starts from a desired architecture. It starts from work that an Agent, model Context, transient process, or human operator is repeatedly forced to reconstruct or coordinate.

The default loop is:

```text
real Agent work
→ observed burden
→ current responsibility carrier
→ smallest externalization hypothesis
→ strong simpler baseline
→ bounded experiment
→ retain / narrow / defer / delete
→ sink a proven capability into the narrowest reusable layer
```

The governing question is:

> Which responsibilities are still placed inside probabilistic model inference, transient sessions, or human operational memory even though they are repeated, formalizable, persistent, shared, verifiable, or precision-sensitive?

Externalization is not automatically progress. A new structure is retained only when it produces observable recurring value greater than its permanent maintenance and coordination cost.

## Default research operator

An Agent is the default operator for ordinary research work. Within an admitted private/research-only scope it may:

- inspect owner-native evidence and existing research records;
- identify repeated token, mechanical, continuity, coordination, verification, drift, or human-runtime burden;
- map the responsibility to its current carrier;
- formulate a minimal externalization candidate and falsifier;
- implement reversible candidates in isolated workspaces;
- execute admitted experiments and consume formal Trial results;
- retain negative results and propose the next Ready Frontier update.

Human attention is not a default research step. It is reserved for changes in purpose or consequence: mission changes, irreversible/public commitments, cross-owner authority transfer, budget expansion, access expansion, or unknown high-consequence effects.

Trial validity remains independent of both the Agent proposer and the human purpose authority. Product and domain owners remain authoritative for their own facts and effects.

## Burden taxonomy

The first scan of a real trajectory asks where scarce cognition is being spent:

| Burden | Typical symptom | Candidate externalization |
|---|---|---|
| Token reconstruction | rereading history to recover current work | bounded working state or retrieval |
| Mechanical translation | model calculates protocol details | semantic Tool plus deterministic lowering |
| Continuity recovery | restart requires transcript reconstruction | durable semantic Run state |
| Coordination and join | Actors synchronize through prose | Artifact, Claim, Join, or Ready Frontier object |
| Verification and completion | model judges its own completion | Completion Contract and independent verifier |
| Drift and invalidation | stale Tool/source knowledge remains active | version binding and invalidation |
| Human runtime | operator repeatedly inspects and tells the Agent what happened | structured inspect, error, recovery, or authority projection |
| Compute orchestration | model simulates branching or recursion in one transcript | programmable compute, bounded specialists, or Run Actor |
| Relational cognitive state | current relations must be reconstructed from chronology | typed Working Set or, only if proven, temporal cognitive relations |

The taxonomy describes where to look. It does not authorize a corresponding subsystem.

## Responsibility placement test

Before building anything, identify four things:

1. the exact responsibility;
2. who or what carries it now;
3. what observable failure occurs when that carrier disappears or is replaced;
4. the narrowest existing classical or Agent-native layer that could own it.

A database being able to store a value is not evidence that the database owns the responsibility. A model being capable of reasoning about a responsibility is not evidence that the responsibility should remain in token space.

## Externalization admission

A candidate enters implementation only when all of the following are explicit:

- real or representative burden evidence;
- a mature classical or simpler Agent baseline;
- a minimal candidate rather than a platform theme;
- measurable expected benefit;
- permanent structures and maintenance cost introduced;
- authority boundary;
- falsifier and deletion path;
- bounded change surface and budget.

This turns the old question, “Should Ordivon have Memory / World / Graph / Prime?” into a stronger sequence:

```text
What burden exists?
Who carries the responsibility now?
Why is that placement wrong?
What is the smallest externalization?
Does it beat the simpler baseline?
If not, delete it.
```

## Evidence hierarchy

The method consumes existing authorities instead of replacing them:

```text
owner-native facts
    ↓
Observation selection
    ↓
Formal Trial validity and outcome
    ↓
Agent research synthesis and externalization decision
    ↓
portfolio / Knowledge / Core proposal
```

Research synthesis may explain evidence; it cannot rewrite the underlying owner facts or make an invalid Trial valid.

## Capability sinking

A useful capability should move downward only as far as its evidence permits:

```text
novel reasoning
→ repeated heuristic
→ structured procedure
→ Agent Tool or adapter
→ Runtime / protocol primitive
→ assumed environment
```

The lower the capability sinks, the less probabilistic cognition future Agents should spend reconstructing it. The corresponding admission bar rises because lower layers create more permanent compatibility and authority cost.

## Relation to Prime-style computation and two-dimensional cognition

These are candidate externalizations at different depths, not architecture commitments.

- Agent-first surfaces externalize deterministic mechanical and environment-adaptation burden.
- Prime-style programmable cognition externalizes compute orchestration, selective Context, branching, and bounded delegation.
- RunFrame and typed Working Sets externalize durable operational state.
- Temporal relational cognition may externalize relations such as support, contradiction, dependency, supersession, and joins only after simpler state and retrieval baselines fail.

The method therefore prefers the lowest-risk externalization first: deterministic mechanics and objective work facts before speculative cognitive semantics.

## First consumer

[`experiments/experiment-loop-v0/`](experiments/experiment-loop-v0/) is the first consumer. Its bounded Propose–Implement–Evaluate–Select–Learn loop is changed from human-managed routine progression to Agent-led progression under deterministic gates. Human attention remains consequence-gated; product promotion remains owned by the affected product/domain authority.

The next consumer is Ordivon Computer itself. Existing structures will be re-audited by measured burden and responsibility placement before any broader architecture reform is admitted. When project evidence challenges a broader assumption rather than a responsibility placement, the result returns to the world-model loop instead of being forced into this externalization method.
