# Computer Method Canon — Core Promotion Assessment

Status: Wave-B assessment. The cross-owner method synthesis is admitted to **Knowledge**. No new Core primitive or responsibility is admitted by this wave.

## Decision

The new synthesis primarily explains *how to research and revise shared claims*. Most of its content remains too procedural, case-rich, or Research-System-adjacent for Core.

Several compact principles are already represented by existing Core/Computer responsibilities rather than requiring new slots:

- owner-native facts remain distinct from shared projection/synthesis;
- evidence, consequence, Effect and accepted completion remain distinct;
- mature classical substrate should own mature mechanics;
- shared responsibilities are retained only after cross-workload failure pressure;
- the world model is revisable through owner-native evidence and cross-project return testing.

Therefore the correct action is **Knowledge promotion without Core expansion**.

## Reopen condition for Core

Reconsider a new/changed Core statement only if a compact method invariant:

1. survives deletion from Knowledge/process guidance while producing a repeated real failure;
2. is independently required by materially different owner workloads;
3. cannot be preserved by existing Core responsibilities or Research-System institutional machinery;
4. remains stable under stronger Agents/providers and mature classical alternatives;
5. can be stated as a responsibility rather than a workflow recipe.

Until then, `knowledge/research-methods/ordivon-research-method-and-paradigm-canon.md` is the canonical reusable synthesis.
