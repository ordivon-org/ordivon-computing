## 0. Question

Recent Ordivon research repeatedly produced deep standings without a proportional change in future Agent behavior. The failure cannot be represented as one generic `research was not consumed` problem.

The relevant chain is:

```text
Research Result
→ durable Standing
→ canonical Representation
→ first-look / recovery reachability
→ concrete future consumer binding
→ default/routine/interface/responsibility change
→ independently observed consequence or justified NO_CHANGE
```

For audit only, this document calls those stages `S0` through `S6`. They are diagnostic coordinates, not a new mandatory state machine.

```text
S0 Result exists
S1 durable Standing
S2 canonical Representation
S3 discoverable / ordinary first-look reachable
S4 bound to a real future consumer
S5 constitutive environment: default/routine/interface/admission/responsibility changes
S6 future consequence independently observed or justified NO_CHANGE demonstrated
```

The key non-equivalences are:

```text
ResearchResult != WorldModel
WorldModel != PersistentEnvironment
Preserved != Discoverable
Discoverable != Consumed
Consumed != Environmentalized
Environmentalized != Beneficial
HistoricallyIntegrated != CurrentlyInhabited
```

## 2. External theory integration — prior art is solved solution space, not deletion pressure

This audit deliberately consumes mature external theory as positive content.

### Organizational memory

Walsh & Ungson's organizational-memory tradition separates acquisition, retention and retrieval and treats memory as past organizational information that can inform present/future decisions. Storage alone is therefore not organizational use.

Ordivon implication:

```text
Git/Host/Atlas retention != later consumer retrieval/use
```

### Absorptive capacity

Cohen & Levinthal's absorptive-capacity framework emphasizes the ability to recognize the value of external knowledge, assimilate it and apply it. Merely finding external prior art is not absorption.

Ordivon implication:

```text
PriorArtFound != PriorArtAssimilated != PriorArtApplied
```

### Organizational learning and routines

Levitt & March characterize organizational learning as routine-based, history-dependent and target-oriented. A report can survive while routine behavior remains unchanged.

Ordivon implication:

```text
StandingPreserved != ResearchRoutineChanged
```

### Infrastructure as relation-in-practice

Star & Ruhleder treat infrastructure relationally: infrastructure becomes meaningful in relation to organized practice rather than as an inert installed object.

Ordivon implication:

```text
CanonicalDocumentExists != ConstitutiveEnvironmentExists
```

### Function allocation / automation / joint cognition

Human-machine function allocation long predates Ordivon. Fitts's 1951 comparative-function work, later levels-of-automation models, Bainbridge's automation ironies and distributed/joint cognition all reject the naive idea that one actor should simply perform every function. Automation can also transform the residual role rather than merely remove work.

Ordivon therefore does **not** claim invention of `assign each function to the best human/machine`.

The remaining Ordivon pressure is narrower: current systems combine replaceable Agents, owner-local truth, separately owned authority/currentness, deterministic mechanics, external-effect/reconciliation boundaries and dynamic consumer interfaces. A historical Human/Agent role bundle can be decomposed without turning the coordinating Agent, database, executor or Human into a universal center.

### Distributed/local knowledge

Distributed-cognition work treats cognition as spanning actors, artifacts and environments. Hayek's narrower epistemic point about dispersed local knowledge also supports skepticism toward one universal knower, although the broader political conclusions of that tradition are outside this audit.

Ordivon implication:

```text
CrossOwnerSynthesis != CentralTruthOwnership
```

### External-theory rule

The correct research operation is:

```text
identify question
→ import strongest applicable mature standing
→ preserve solved subspace and assumptions
→ test transport/composition under current boundary conditions
→ investigate only residual/bridge if one survives
→ STOP / NO_CHANGE if mature theory + owner bindings suffice
```

Hence:

```text
SubtractFromNovelty != SubtractFromSolutionDomain
SolvedSubspace != DeletedProblemDomain
```

## 12. Failure taxonomy

The audit requires several distinct debts rather than one `consumption` bucket:

1. **Capture debt** — Result never becomes durable standing.
2. **Destination/promotion debt** — durable standing exists but its truthful reusable owner/destination is never adjudicated.
3. **Lineage-survival/migration debt** — historically integrated reusable standing is stranded by branch split, owner migration, contraction or rewrite.
4. **First-look/retrieval debt** — canonical material exists but ordinary relevant work does not naturally encounter it.
5. **Consumer-binding debt** — discoverable standing is not selected/bound by any concrete future consumer.
6. **Environmentalization/routine debt** — consumer sees the knowledge but defaults, routines, interfaces, tests or responsibility placement do not change.
7. **Consequence debt** — a default changes but there is no independent evidence of benefit/harm/NO_CHANGE.
8. **External-elimination debt** — mature prior art is used to erase a problem domain instead of preserving its solved subspace and testing the residual boundary.

Different repair mechanisms apply to each. A universal `research memory system` would collapse these distinctions and is rejected.
