# AI Capability Governance Research Data

This directory is reserved for version-bound, machine-readable records produced
by G3-G6 of `studies/2026-ai-capability-governance-and-private-power/`.

Expected collections:

```text
provider-policies/
policy-revisions/
access-programs/
enforcement-events/
regulatory-actions/
controlled-observations/
```

G0-G2 stores only a hypothetical example. Do not commit credentials, personal
account identifiers, raw flagged conversations, third-party sensitive content,
or evidence whose publication would create a reusable harmful capability.

The study-local JSON Schemas remain authoritative until a later closeout decides
to retain, shrink, replace, or delete them.
