# AI Capability Governance Research Data

This directory contains version-bound machine-readable records produced by G3-G7
of `studies/2026-ai-capability-governance-and-private-power/`.

Current collections:

```text
controlled-observations/
  DeepSeek API-surface portability Pilot and confirmation
  R6 Provider/model/Host/Runtime/World layer reclassification

provider-cases/
  seven normalized Provider governance modes

institutions/
  five state, regulatory, compute and cloud cases

graphs/
  governance graph
  dependency graph
```

The data is a research-local projection, not a Provider score, user-risk system,
policy engine, graph service, or Protocol contract.

Do not commit credentials, personal account identifiers, raw flagged
conversations, raw Provider responses, third-party sensitive content, or evidence
whose publication would create a reusable harmful capability. Controlled
observations retain bounded facts, metadata, digests, error classes, and aggregate
results only.

The study-local Schemas, generators, and validators remain authoritative until
the requested full review decides to retain, freeze, revalidate, split, replace,
or delete the records. G8 architecture promotion is intentionally omitted.
