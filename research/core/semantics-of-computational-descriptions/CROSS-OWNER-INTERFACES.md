# SCD Cross-Owner Interfaces

## Computational Possibility

CP imports constituted meaning/evaluation/preservation semantics and owns regime-relative possibility, witnesses, reductions, comparative power, and abstract resource/complexity. CP references SCD truth; it does not copy it.

## Runtime

Runtime owns actual admitted-operation realization, execution/lifecycle, persistence/evidence, support/reuse/discharge, and invalidation/revalidation. SCD owns abstract computational-description semantics such as compatibility, equivalence/refinement, composition, and preservation. Concrete Runtime binding to those semantics is a cross-owner bridge, not dual canonical ownership.

## Network

Network owns actual qualified cross-locus capability, topology, resolution, forwarding, and service realization. SCD may supply semantic predicates used by Network contracts.

## Harness

Harness owns task/context/invocation/run/tool/control orchestration. It may carry semantic representations or contracts without owning SCD semantic truth.

## World and other source owners

Physical realizability, causation, security, normative authority, human truth, and source-domain problem/value truth remain with their respective owners.
