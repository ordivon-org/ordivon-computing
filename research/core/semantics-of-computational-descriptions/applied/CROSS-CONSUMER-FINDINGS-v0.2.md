## 3. Preservation is typed by what is preserved

Observed regimes now include:

- **historical preservation** — result remains valid history but not current authority;
- **referential/recoverable preservation** — bounded reference can recover exact authoritative state;
- **abstract/claim-selective preservation** — summary preserves selected claims but not full contract;
- **projection fidelity** — exact current model view depends on provenance/digest/interface correspondence;
- **capability currentness** — executable authority is Run/turn scoped;
- **realization admissibility** — semantic validity does not ensure a current concrete Runtime realization;
- **evidence-scope preservation** — Runtime evidence supports only the physical claim it actually proves.

A generic `preserved=true` flag is therefore structurally misleading.
