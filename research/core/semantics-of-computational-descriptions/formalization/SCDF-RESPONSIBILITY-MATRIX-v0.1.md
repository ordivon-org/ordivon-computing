## Residual map

### Reachability / Alias-Separation

Many local regimes have mature alias/reference/heap/process/network theories. It remains the strongest SCD residual only if a cross-regime semantic responsibility survives after those reductions.

### Name Identity / Generativity

Nominal sets/logic and related name/binding work strongly cover alpha-equivalence, freshness and generative-name semantics. The remaining SCD question, if any, is broader DescriptionIdentity across carrier changes, branches and heterogeneous semantically equivalent rewrites.

### Resource Usage / Ownership

- abstract possibility/complexity → Computational Possibility;
- actual resource occurrence/evidence → Runtime;
- meaning/satisfaction/preservation of resource annotations → possible SCD responsibility.

Current pressure looks boundary-heavy rather than like a new independent SCD Foundation.

# Candidate SCD-specific formal gaps

These are **gap candidates only**, not Foundations or novelty claims.

## G1 — Multi-Framework Semantic-Obligation Coordination

One description lifecycle step can require abstraction, refinement, context, transport and currentness obligations supplied by different mature theories. Research question: how can these obligations be coordinated without inventing a fake universal semantics?

## G2 — Owner-Typed Dependency Currentness

A semantic claim can depend on an external owner-native fact whose current authority/version changes while the local semantic framework does not. Research question: how should `Stand(φ | S,Δ)` react without copying external truth or globally invalidating unrelated claims?

## G3 — Description Identity Across Heterogeneity

Carrier identity, alpha-equivalence, semantic equivalence and lineage identity are distinct. Research question: does SCD need an irreducible description-identity/currentness notion across branches, transport and rewrite, or can identity remain derived?

## G4 — Correspondence Composition

Framework-specific `μ` can be a simulation, refinement, abstraction relation, signature/sentence/model translation or embedding. Research question: when does composition `μ2∘μ1` support valid cross-framework standing transport, and when does it fail?

No universal commutation is assumed.
