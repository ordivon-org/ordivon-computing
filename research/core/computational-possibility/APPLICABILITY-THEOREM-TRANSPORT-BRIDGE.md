# Applicability / Theorem-Transport Bridge

Applicability/theorem transport is a **derived cross-owner bridge**, not a Foundation.

The canonical semantic blocks are:

1. `ClaimScope`
2. `TargetScope`
3. `TransportBurden`
4. `PremiseEvidence`
5. `Verdict`

Optional quantitative structure lives under `TransportBurden`.

Direction is theorem-family sensitive:

- constructive / upper claims: formal → actual implementation/embedding plus required preservation and quantitative domination;
- impossibility / lower claims: actual → formal coverage/abstraction plus required preservation and quantitative reflection.

A formal-to-actual implementation alone cannot establish a lower bound over all actual implementations.

Owner-authoritative premises are referenced with scope/currentness; they are not copied into timeless CP truth.
