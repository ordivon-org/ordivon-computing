## 10. Currentness failure modes

The following recoveries are invalid:

- `Host READY -> therefore resume that historical research route`;
- `Algorithmics was canonical once -> therefore Algorithmics is current canonical identity`;
- `AlgF0 was frozen -> therefore AlgF0 is still a current Foundation`;
- `D3 was selected next -> therefore Proof Search is the current next route`;
- `Broad Computing contains both S and T history -> therefore Broad Computing is the current owner`;
- `shared repository -> shared semantic authority`;
- `project-formation document is newer -> therefore it may rewrite established source research history`.

Currentness is semantic and supersession-aware, not timestamp-only, READY-state-only, or repository-location-based.
