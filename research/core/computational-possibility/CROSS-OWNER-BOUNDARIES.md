# Computational Possibility Cross-Owner Boundaries

## SCD / source semantics

Meaning, interpretation, equivalence/refinement, and preservation are imported from SCD or the source owner. CP reasons over those constituted semantics.

## Runtime

Runtime owns actual execution, attempt lifecycle, persistence, actual resource availability/consumption, and operational evidence. CP owns abstract regime-relative possibility and resource/performance theorems conditional on declared projections.

## Interlocus

Interlocus owns actual reachability, topology, routing, bandwidth, and communication capability. CP may model communication constraints only through an explicit regime/interface projection.

## World

World owns physical realizability and substrate truth.

## Harness

Harness owns concrete Agent/tool/run orchestration and provisioning.

## Security / Statistics / source-domain owners

Security authority/adversarial truth, empirical/statistical validity, and source-domain value/problem authority remain external premises.
