# 5. Direct B-vs-I theorem-form attack

Round I states a generic interface:

```text

there exists / does not exist an admitted solver A.
```

If `P` is allowed to contain an arbitrary resource constraint supplied by B, then:

```text
ResourceBoundedFeasible(Ω, Γ)
=
∃ A .
  SolverFor(A, Ω, M)
  ∧ ResourceProfile_B(A, M) satisfies Γ
```

But this does not eliminate B's resource relation.
The existential statement is impossible to evaluate without B supplying:

```text

measurement/accounting semantics
scale/reference family
aggregation regime
bound/budget/comparison relation
```

Hence:

```text
ExistentialQuantifier
!= ResourceMeasure

SolverExists
!= ResourceProfile

ResourcePredicate
!= ExistentialQuantification
```

The correct composition is:

```text
bounded feasibility
= ordinary existence
  applied to a T-owned resource-bounded witness predicate
```

not:

```text

```

and not:

```text
B owns generic existence
```
