## 1. Why this programme exists

Ordivon has spent substantial effort separating semantic owners so that one useful abstraction does not silently become a universal truth authority. That decomposition is now strong enough to expose a different failure mode:

```text
owner separation
→ local depth
→ strong local theory / machinery
→ weak deliberate cross-owner composition search
→ system capability grows more slowly than owner capability
```

The programme asks a stronger question than integration:

> **When independently truthful owners are composed without transferring their authority, which capabilities appear that no proper subset of those owners can provide for the same real workload?**

The motivating hypothesis is that owner-preserving composability may be an important source of non-additive capability, higher-order interaction, emergence, and in some regimes threshold-like or phase-transition-like behavior. None of those stronger labels is pre-admitted.

This programme therefore changes the unit of search from only:

```text
owner frontier → deeper owner research
```

to also:

```text
owner frontiers
→ cross-owner composition search
→ natural consumer
→ factorial / coalition subtraction
→ owner-native consequence
→ localize, retain, or reopen the responsible owners
```

## 2. Constitutional boundary

COJC is **not** a new semantic owner, composition service, capability registry, workflow engine, or shared truth store.

The programme owns only:

- the cross-owner research question;
- experiment contracts and controlled comparisons;
- interaction/complementarity attribution under a named workload;
- compact cross-owner synthesis and negative results;
- evidence for deciding whether a real residual responsibility should return to an existing owner or, only after independent repeated pressure, be considered for Computing promotion.

Owner-native truth remains owner-native. In particular:

- SCD retains semantic meaning/equivalence/refinement/preservation truth;
- Computational Possibility retains regime-relative achievability, witness and frontier truth;
- Interlocus retains qualified cross-locus capability, binding, realization and currentness truth;
- World retains exact external trajectory/binding/reconciliation responsibility while external providers keep native occurrence truth;
- Security retains adversarial-domain authority, evidence and consequence semantics;
- Normative retains permission/obligation/validity/jurisdiction semantics;
- Harness retains bounded Agent Run structure and cognition mechanics;
- Runtime retains physical execution truth;
- Host retains semantic work continuity;
- domain owners such as Finance, Game, Media, Web and Human retain their domain consequences.

The programme explicitly rejects the inference:

```text
shared semantic interaction
⇒ shared executable machinery
```

and also rejects the opposite inference:

```text
no shared machinery earned
⇒ no important cross-owner composition exists
```

## 4. External methodological priors

External work is used here as a method supplier, not as proof about Ordivon.

- Higher-order network research shows that interactions among three or more units can produce dynamics that are not captured by pairwise decomposition. See Zhang, Lucas & Battiston, *Nature Communications* (2023): https://www.nature.com/articles/s41467-023-37190-9
- Recent work shows that topology and higher-order interaction structure can participate in abrupt/explosive transitions in some dynamical systems. See Malizia et al., *Nature Communications* (2025): https://www.nature.com/articles/s41467-024-55506-1
- Partial Information Decomposition distinguishes unique, redundant and synergistic information, where synergistic information is available only from joint sources. This is a useful analogy for measurement discipline, not an automatic Ordivon metric: https://pmc.ncbi.nlm.nih.gov/articles/PMC7512824/
- Supermodularity provides a mature formal language for complementarity and systems effects when a legitimate ordered objective exists. See Milgrom & Roberts, *Complementarities and Systems*: https://milgrom.people.stanford.edu/wp-content/uploads/2021/08/Milgrom-Roberts-Complements-Japan.pdf

The programme will borrow these ideas only when their assumptions match the owner-native workload. It will not force every capability into one scalar utility or one hypergraph formalism.

## 5. Operational definitions

Let `W` be a frozen workload, `S` a subset of admitted owner contributions/treatments, and `O_W(S)` the owner-native outcome record under that treatment set.

A target predicate `P_W(O)` must be frozen before the decisive run whenever possible.

### 5.1 Coexistence

Several owners are present, but deleting one does not change the target outcome or justified decision.

This is **not composition evidence**.

### 5.2 Additive / separable composition

Owners contribute independently and their joint effect is adequately predicted from the component effects under the chosen metric or predicate.

This may be useful engineering integration without non-additive capability.

### 5.3 Complementarity

For a legitimate owner-native metric, ordered outcome, or frozen target predicate, the joint treatment has value not attributable to the sum/union of isolated treatment effects.

For a two-factor scalar metric when subtraction is meaningful:

```text
I(A,B) = Y11 - Y10 - Y01 + Y00
```

For binary target closure, the strongest simple pattern is:

```text
P(∅)=0, P(A)=0, P(B)=0, P(A,B)=1
```

This does **not** by itself establish emergence.

### 5.4 Higher-order irreducible joint capability

For a set `S` with `|S| >= 3`, a target capability is higher-order irreducible when the full treatment satisfies the target and every feasible proper subset fails it under the same workload and world conditions, without manufacturing those failures.

Where scalar interaction analysis is legitimate, Möbius/inclusion-exclusion contrasts may be used. Where it is not, preserve the owner-native outcome vector and use frozen predicates/partial orders instead.

### 5.5 Emergent capability candidate

Use this label only when all of the following hold:

1. **irreducibility:** a capability or decision class is not available to feasible proper subsets;
2. **non-tautology:** the outcome is not definitionally guaranteed by simply conjoining the input interfaces;
3. **stability:** the effect survives a frozen holdout, nearby world variation, or a materially different consumer;
4. **new macro freedom:** the joint system acquires a new reachable transition, policy family, recovery mode, prediction/control capability, or useful abstraction boundary;
5. **macro usefulness:** a higher-level joint-capability description improves prediction, control, recovery or transfer without needing to replay all component internals;
6. **owner preservation:** no result depends on silently moving truth authority into the experiment layer.

### 5.6 Phase-transition candidate

Do **not** call a discrete `off/off/off → on` factorial result a phase transition.

A phase-transition candidate additionally requires a parameterized family of neighboring conditions and evidence of a qualitative regime change around a threshold or control surface, for example:

- reachable-state class changes sharply;
- stable policy/coordination mode changes;
- recovery basin changes;
- feedback creates a new persistent attractor;
- capability suddenly becomes robust across a region rather than at one isolated point.

The threshold must be reproduced and separated from evaluator discontinuity or hand-coded gating.

## 6. Evidence ladder

Use the weakest label supported by evidence:

| Level | Label | Minimum evidence |
|---|---|---|
| J0 | coexistence / candidate | plausible owner interaction, named consumer, no causal claim |
| J1 | composition | deletion/ablation changes a real owner-native outcome |
| J2 | complementarity | feasible factorial/coalition evidence shows non-additivity |
| J3 | higher-order irreducibility | full `k`-way set succeeds while all feasible proper subsets fail, with no manufactured failures |
| J4 | emergent capability candidate | J3 + holdout/transfer + new macro freedom + useful higher-level predictive/control boundary |
| J5 | phase-transition candidate | J4 + parameter sweep/neighboring regimes + replicated threshold-like qualitative change |
| J6 | stable cross-owner law | materially different consumers reproduce the relation strongly enough to change Computing world-model or promoted contracts |

No experiment is rewarded for reaching a higher label.

## 7. Search strategy without combinatorial explosion

With `n` owners, exhaustive subset search is usually the wrong first move. COJC uses demand-first sparse search.

### Step A — start from a blocked or capability-limited consumer

Prefer:

- a real owner workload that cannot currently reach a desired transition;
- a natural failure/recovery boundary;
- a repeated operation where two owner truths are manually joined;
- a current domain where adding one owner changes the Agent's action space.

Do not begin from arbitrary owner pairs because they exist.

### Step B — decompose the missing target predicate

Ask which independent responsibilities are actually required:

```text
semantic adequacy?
computational feasibility?
current cross-locus realization?
permission/authority?
adversarial robustness?
physical execution?
external consequence/recovery?
representation/cognition?
```

This creates a small candidate complement set.

### Step C — run cheapest valid subset tests

- static consumer/deletion audit first;
- deterministic counterfactual second;
- factorial/coalition ablation only when arms are naturally feasible;
- live model/provider/world tests only after the outcome contract is frozen;
- human/market tests only for claims that cross into those truth domains.

### Step D — escalate from pairwise to higher-order only when justified

A triad or larger set is prioritized when:

- pairwise arms carry distinct partial responsibilities but none closes the target;
- a known owner boundary forms a gate that pairwise models cannot represent;
- a real world change activates/deactivates a third factor;
- previous pairwise attribution is unstable or contradictory.

### Step E — retain negative space

A failed interaction, redundant factor, manufactured-baseline warning, or owner-local explanation is a first-class result. It prevents repeated rediscovery.

## 10. Promotion, contraction, and stop rules

A cross-owner result does **not** justify shared infrastructure merely because it is synergistic.

Promote a cross-owner contract only if:

1. a stable relation is reproduced in materially different consumers;
2. owner-local composition repeatedly fails or causes material manual/Agent burden;
3. the residual responsibility cannot be placed more cleanly in an existing owner;
4. the shared waist has explicit current consumers and recovery semantics;
5. a deletion/localization condition is named.

Contract or stop COJC if:

- interaction searches repeatedly reduce to ordinary conjunctions already handled by owner interfaces;
- natural candidates cannot produce identifiable interventions without manufacturing failures;
- the programme becomes a static matrix/catalog rather than changing real experiments or decisions;
- owner-local consumer work discovers useful combinations more cheaply than Computing can;
- `emergence` becomes a rhetorical reward rather than a stricter evidence label.
