## 1. The central causal object is not “rationale”

The reusable chain is:

```text
pressure / question
→ strongest attractive rival
→ discriminating observation / deletion / ablation
→ retained invariant
→ engineering consequence
→ predicted breakage if rival returns
→ negative-transfer boundary
→ reopen condition
```

This is stronger than an ADR saying “we chose X because Y.” It preserves the search boundary: **what was tried, why it was reasonable, exactly what changed the decision, and under what new conditions the old option deserves another trial.**

## 2. Host is the clearest live Causal-Recovery Debt sample

Current Host correctly states that its former generic executor-neutral Effect lifecycle duplicated specialized paths and was removed. But the *shape of the rival*—`EffectLifecycleHost`, DispatchEnvelope, generic deliver/observe/reconcile, WAITING/VERIFYING, Game workload—only becomes concrete by returning to deleted commit `06ef7a3...`.

That is real debt, but it does **not** imply Host needs 1,400 lines of old code or a long history essay restored. OFR3 can preserve the rival compactly while Git remains the reproducibility substrate.

## 3. Stronger mechanism can be the rejected model

Runtime is an important anti-story. The rejected memfd path was not sloppy or weaker: it produced *better exact-byte immutability*. It lost because it changed `__file__`, `argv[0]` and `/proc/self/exe`.

So the causal lesson is not “use weaker isolation.” It is:

> **A mechanism that improves one invariant may still be wrong if it changes the world whose behavior the evidence claims to describe.**

This is exactly why `strongest_rival_and_attraction` survives the OFR3 field ablation.

## 4. “Rejected” has several evidence meanings

OFR3 found at least five materially different falsifier forms:

- **empirical physical counterexample** — Runtime path realization;
- **deletion/existence test** — Host generic Effect lifecycle;
- **controlled state/authority experiment** — Harness, Workstation, Security, Game;
- **model competition** — World and Finance;
- **ablation/rendered treatment** — Human and Web.

A future Theory Unit must not collapse all of these into a generic confidence score. The type of discriminator tells a future Agent what kind of evidence could overturn the result.

## 5. Negative knowledge must remain conditional

Every case carries both a `boundary` and `reopenCondition`.

Examples:

- memfd is not globally banned;
- Resource family models are not “false”; C was strong but unearned as universal execution taxonomy;
- Security prospective revocation does not mean future access survives revoke;
- Web entity exposure is not a universal above-the-fold rule;
- Game removed structures are burden-of-proof records, not constitutional bans.

Without this pair, negative knowledge becomes architecture ideology.

## 6. OFR3 result for OFR4

OFR3 does **not** yet define a Theory Unit schema. It does identify eight semantic roles that all useful compressed reconstructions need to keep recoverable:

```text
claim + scope
strongest rival + why it was attractive
decisive discriminator/falsifier
retained consequence
counterfactual breakage
negative-transfer boundary
reopen condition
exact evidence/currentness references
```

Exact implementation detail and full experiment apparatus can usually stay external behind revision-bound references.
