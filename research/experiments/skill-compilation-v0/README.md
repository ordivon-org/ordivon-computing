# Skill Compilation v0

Status: **P3 complete — first natural Skill candidate rejected.**

This experiment asks whether repeated Agent-side Tool composition should be compiled into a reusable Skill, without assuming a Skill repository, runtime, marketplace, registry, or new execution authority is needed.

## Discovery

Two repeated patterns were separated before live evaluation. `source-landing-publication` was rejected at admission because it is deterministic Git/Runtime mechanics plus explicit publication consequence, not a new Agent capability. Repeated UNKNOWN/response-loss reconciliation across Runtime and Host exposed a genuine procedural burden, so the compiler produced the research candidate `skill:reconcile-before-redispatch:v1`. The candidate owns only reusable procedure/knowledge; actual execution remains with existing Tool, Runtime, Host, Git, and domain authorities.

## Live falsification

The first 25-trajectory DeepSeek campaign suggested mechanism value (Skill 8/10 vs baseline 4/10 development) but its evaluator vocabulary had overlapping actions and an ambiguous redispatch boolean. The raw evidence was frozen and the scientific selection invalidated; it was not retrospectively rescored.

The candidate Skill bytes were kept unchanged. A repaired evaluator removed synonymous actions and the redundant boolean, exposed the same operation-specific Tool contract fact to both treatments, and froze five new holdout cases. In that second 25-trajectory campaign the strong baseline scored 8/10 development while the Skill scored 6/10. The Skill used more Provider tokens and sometimes made the model's structured action selection less reliable even when its free-text summary described the right procedure. Baseline then passed only 3/5 holdout, so no stable recovery capability was established by either treatment.

## Decision

The candidate is rejected and remains evidence only. No Skill runtime, repository, marketplace, central registry, or Harness/Runtime execution feature is authorized. The reusable lesson is narrower: repeated composition is only a discovery signal; a Skill must add measured decision value beyond current Tool contract facts and must not duplicate execution authority.

P2's bounded cross-evidence recursive self-improvement evidence remains intact. Dynamic Skill compilation remains unproven. The next materially different adaptation falsifier is `ANC-MULTI-001`: one Goal, two independent Tasks, two Artifacts, and one deterministic Join versus a strong single-Agent plus independent-verifier baseline.
