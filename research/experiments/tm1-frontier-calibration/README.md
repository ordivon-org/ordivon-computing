# TM1 — Prospective Research Frontier Calibration

TM1 is the first prospective consumer of the TM0 research-taste hypothesis.

It freezes a real cross-project candidate-question frontier **before** live Provider selection and compares the same DeepSeek model under two conditions:

- **baseline** — ordinary research-selection instruction;
- **taste** — the same instruction plus six compact, defeasible TM0 priors about burden, discrimination, closed-loop cost, reversibility, information selection, and lawful stopping.

The campaign has two stages.

## Stage A — frontier selection

Seven current owner questions are shuffled and ranked independently across matched replicates. The predeclared actionability classes are not shown to the Provider. They do not claim universal value; they encode only whether this Computing campaign can currently obtain bounded, low-consequence, owner-native evidence.

The experiment measures whether each treatment:

- places an immediately bounded class-A question first;
- includes both class-A questions in the first three positions;
- defers both currently blocked/high-consequence class-D questions;
- avoids putting a class-D question in the top two.

No scalar tractability score is used.

## Stage B — discovery efficiency

The live owner consumer is Harness `H-NOTOOL`, frozen at exact Harness revision `999d7535242b14c432cd14527ec109f2c6749969`. The Provider receives the real owner pressure, the exact Python path catalog, and only three read-only actions: literal search, bounded file read, or submit/abstain.

The hidden evaluator is deterministic and checks whether the Agent localizes the pressure to the interaction between `ordivon/loop.py` conclusion-correction state binding and `ordivon/sqlite_agent_bridge.py` no-Tool state admission, while preserving the no-Tool authority boundary. It scores localization and causal concepts; it does **not** score a proposed patch as correct.

The key measure is whether a causally useful localization can be reached in a small observation budget rather than P4-style near-complete source coverage.

## Scientific boundary

TM1 tests a **research-selection representation**, not a product subsystem. Positive evidence can justify retaining a compact research-taste representation for further trials. It cannot justify a scheduler, universal question score, ResearchTasteService, or automatic Core rewrite.

A negative or null result is equally useful: it would show that the compact priors add prompt/context cost without improving frontier or observation selection for this consumer.
