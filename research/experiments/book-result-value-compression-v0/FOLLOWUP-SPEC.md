# Exploratory Composite Follow-up

This follow-up was designed **after** the primary A/B reached a baseline ceiling. It is exploratory and cannot retroactively change the primary admission rule.

Purpose: challenge the alternative explanation that the primary single-answer options made the task too easy. Each case now requires recovering the complete set of justified Result/Value relations from nine possible labels. Overclaim and underclaim are both scored as errors.

Arms remain identical to the primary experiment:

- baseline = exact five-chapter Book;
- treatment = frozen compact map before the same exact Book.

Same model/provider, zero Tools, same frozen case order, three fresh accepted replicates per arm. The composite cases and their oracle are hashed before the first follow-up run.

A treatment advantage here may support **representation/reconstruction value**, but without a primary decision delta it still does not establish a correctness-motivated Book mutation. Human readability/retention remains outside this Agent-only experiment.
