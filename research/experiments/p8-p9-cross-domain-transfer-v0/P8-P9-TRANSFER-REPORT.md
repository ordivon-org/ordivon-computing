## P9 — Finance stopping transfer

The Finance universe is deliberately unlike the previous Runtime Git search. Six frozen owner datasets were queried through DuckDB one dataset at a time: holdability, wrapper screen, instruments, historical funding settlements, swap daily bars, and index daily bars. The hidden oracle contains 12 descriptive state fields for SPY/QQQ/XAU/SMH. Every Trial queried an immutable copied Parquet snapshot; the final cross-check proved all six `inspect_dataset` outputs equal the frozen mechanically computed summaries.

### Same-context self-stop

All 6 replicates inspected all 6 unique datasets. Five then repeated already-frozen datasets until the 8-observation ceiling and never submitted. Only one submitted at observation 6, and it was 11/12 because it misidentified the latest tracking-error leader. Therefore self-stop was **0/6 strict** even with an explicit, finite, completely covered universe.

At five datasets the only universally missing field was exactly the field owned by the unobserved `index_daily_bars` dataset. Adding the sixth dependency closed all six trials. This is stronger than a fixed observation-count rule: on the previous Runtime workload one high-density search observation was sufficient; here six independent dataset observations were necessary. The meaningful coordinate is **decision-relevant evidence dependency coverage under the operator's information structure**, not the integer observation count.

### Full-evidence order perturbation

Coverage is not sufficient for order stability. With the identical six dataset summaries, six permutations × six replicates produced 34/36 strict results. Canonical, bars-first, identity-first, funding-first and interleaved orders were each 6/6; the reverse order was only 4/6, with two errors on `latestTrackingErrorLeader`. Thus fresh synthesis breaks acquisition inertia but does not erase semantic path dependence.

The surviving P9 law becomes:

```text
bounded evidence acquisition
  -> decision-relevant dependency coverage
  -> fresh synthesis context
  -> explicit unresolved fields / current world model

with: evidence order/path remains an independent falsifier
```

Do not promote a fixed checkpoint count, StoppingService, CriticService, or the claim that complete evidence is order-invariant.

## Cross-domain world-model update

1. Applicability basis now has independent cross-domain support: Runtime/Host consequence decisions and Security derived evidence converge on planning/derivation-time exact dependencies rather than generation/currentness.
2. More raw current context is not monotonically safer. Scoped dependency comparison can sacrifice some progress while reducing false carry.
3. Search inertia survives even when the evidence universe is explicitly finite and already fully observed. A correct instruction not to repeat frozen datasets does not create stopping competence.
4. Fresh synthesis is now supported across source-code and structured-data worlds, but its boundary is evidence-structure dependent.
5. Dependency coverage is a better stopping coordinate than observation count, yet complete coverage is not a proof of order/path invariance.
6. No new shared product surface is justified by these results.
