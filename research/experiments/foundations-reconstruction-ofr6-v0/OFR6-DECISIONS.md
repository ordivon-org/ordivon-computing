## Two Core refinements

### C2 → A10: UNKNOWN must not collapse when action differs

The prior Core already preserved uncertainty for lost Effects and conflicting evidence. OFR2's five-owner A-grade convergence is broader: missing, stale, conflicting, or insufficient evidence can imply a different next action from false, absent, failed, or safe-to-retry. A10 now says this directly.

This promotes **no Unknown object**. Each owner still defines why a state is unresolved and how to recover.

### C4 → primitives Contract: identity is invariant-bound

Task/Effect/Context semantics already implied identity across implementation change. OFR2 adds independent Finance, Workstation, Security and Runtime failures. The compact surviving statement is negative and owner-bounded: label/byte/ticker/name/revision equality alone is neither necessary nor sufficient; the owner names the invariants whose change alters meaning, authority, replay or continuity.

This promotes **no universal identity tuple**.
