# J1 — Adversarial Interlocus Consumption

Status: **READY / design frozen; physical experiment not yet executed**.

J1 is the first new COJC experiment selected by J0. It deliberately narrows the broader Interlocus × Security × World candidate to **Interlocus × Security** because Security already owns the authoritative controlled Range and independent topology truth needed for this test. Ordivon World is not added by symmetry.

## Research question

> In the same adversarial Security Range, does consuming Interlocus-owned binding/currentness/migration distinctions improve a Defender's ability to maintain the intended service capability under deceptive/stale relation evidence, relative to a strong Security-local raw-topology/evidence baseline?

This is a cross-owner **deletion/consumption** experiment first. It is not yet an emergence experiment.

## World

Use an owned Security `RangeSession`-style environment with:

- one legitimate service capability;
- one initial legitimate binding;
- a controlled rebinding/migration event;
- one deceiver that can publish a stale or false receiver-visible binding/reachability claim;
- independent Security/Host topology truth unavailable to the deceiver;
- no unrestricted external target;
- no Ordivon World external effect unless later evidence proves it is necessary.

## Arms

### Control — Security-local baseline

Expose the strongest current Security-native evidence required by the task, including raw topology observations/provenance and adversarial claims, but **without** an Interlocus-qualified projection carrying explicit claim-epoch, binding-transition and role-specific currentness structure.

### Treatment — Interlocus-qualified projection

Use the same underlying Security evidence and Agent/model/tool budget, but compile a bounded source-fenced Interlocus projection preserving only the distinctions relevant to the operation:

- reference/binding identity;
- claim epoch / migration boundary;
- current vs historical binding evidence;
- serviceability/currentness role distinctions;
- explicit prohibition on unwitnessed cross-epoch evidence splicing.

The projection must not contain an action recommendation or embed the correct final choice.

## Target outcome

A successful treatment must establish all of:

1. do not act on the stale/deceptive binding as current authority;
2. identify when the current binding is `UNKNOWN` rather than inventing continuity;
3. acquire/admit the minimum additional observation if needed;
4. continue through the legitimate current binding after migration/rebinding;
5. preserve history without treating old reachability/binding as present truth;
6. leave Security consequence/evaluator truth with Security.

## Falsifiers

J1 is negative if:

- the strong Security-local control performs equivalently with lower complexity;
- Security already carries all decisive distinctions natively, producing `NO_CHANGE`;
- the Interlocus projection merely restates the correct answer;
- the treatment increases action errors or blocks valid recovery;
- current Interlocus standing cannot be mapped to the Security consumer without inventing new shared semantics.

A negative result does not reopen Interlocus or Security Foundations by default.

## Escalation rule

Only after a positive J1 deletion result may COJC consider a factorial/higher-order successor. Ordivon World enters only if an independently authoritative external effect/trajectory creates an ambiguity that Security + Interlocus cannot own cleanly.
