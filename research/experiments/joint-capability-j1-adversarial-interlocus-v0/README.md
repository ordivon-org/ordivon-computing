# J1 — Adversarial Interlocus Consumption

Status: **CLOSED — no deletion-essentiality established**.

Canonical closeout: [`J1-CLOSEOUT.md`](./J1-CLOSEOUT.md)
Machine-readable summary: [`result-summary-v1.json`](./result-summary-v1.json)

J1 was the first new COJC experiment selected by J0. It deliberately narrowed the broader Interlocus × Security × World candidate to **Interlocus × Security** because Security already owns the authoritative controlled Range and independent topology truth required for this test. Ordivon World remained subtracted.

## Research question

> In the same adversarial Security Range, does consuming Interlocus-owned binding/currentness/migration distinctions improve a Defender's ability to maintain the intended service capability under deceptive/stale relation evidence, relative to a strong Security-local raw-topology/evidence baseline?

This was a cross-owner **deletion/consumption** experiment, not an emergence experiment.

## Frozen arms

### Control — Security-local baseline

The strongest Security-native evidence required by the task, including `world-truth / management / sensor / contested` distinctions, without an Interlocus-qualified epoch/currentness projection.

### Treatment — Interlocus-qualified projection

The exact same underlying Security evidence, model/tool/budget/evaluator, plus a bounded source-fenced Interlocus projection preserving relation distinctions such as:

- binding identity;
- migration/claim epoch;
- current vs historical applicability;
- non-automatic transport of standing across migration;
- prohibition on unwitnessed cross-epoch splicing.

The projection carried no Security authority and no action recommendation.

## Executed campaigns

1. **48-trial live campaign** — both arms were action-safe on all valid structured results; treatment used ~26% more tokens. Theory-bearing scenario labels created a possible representation leak.
2. **32-trial neutral-label robustness campaign** — neutralized labels exposed one weak-model Security-control safety error while treatment remained safe in that small run.
3. **40-trial preregistered N2 replication** — control produced 3/20 safety errors and treatment 1/20; all four occurred in `deepseek-v4-flash`. `deepseek-v4-pro` solved both arms 10/10. One-sided Fisher control>treatment was descriptive `p=0.3025`.
4. **40-trial adaptive mechanism ablation** — raw control 1/10 safety error, generic caution fence 2/10, epoch-structure-only 0/9 valid, full Interlocus 0/10. This disfavors a generic extra-warning explanation and points toward relation epoch/currentness structure as the narrower error-shaping candidate, but it is not an independent holdout.

Across the four executed campaigns: 160 planned trials, 156 valid structured results, 4 apparatus-invalid results kept separate from semantic scoring. The final 40-trial mechanism ablation is adaptive evidence, not an independent confirmation set.

## Final disposition

J1 does **not** establish Interlocus × Security scoped complementarity or deletion-essential capability.

What it does establish is narrower and useful:

> The same sufficient owner evidence can produce different error distributions under different relation/currentness representations for a finite consumer.

In compressed form:

`Evidence sufficiency != Representation sufficiency`

but:

`Representation benefit != Capability irreducibility`.

The effect was model/capacity-sensitive and disappeared in the stronger tested model. The treatment itself was not sufficient, since it also produced one unsafe premature-successor action. Adaptive ablation further suggests that the narrower mechanism is structured epoch/currentness geometry rather than generic caution text, while still leaving standing-level errors.

## Rejected escalations

This result is not evidence for:

- emergence;
- higher-order irreducibility;
- phase transition;
- generic Interlocus projection superiority;
- moving Security truth/authority ownership;
- shared production machinery;
- adding Ordivon World to J1.

## World re-entry gate

World enters a future successor only when two external realities are indistinguishable to Security + Interlocus while requiring different correct actions:

`P(Security+Interlocus, R1) = P(Security+Interlocus, R2)`

and

`CorrectAction(R1) != CorrectAction(R2)`.

That external-effect/trajectory non-identifiability condition was absent in J1.

Any later Interlocus × Security experiment must introduce a genuinely new natural consumer pressure rather than repeatedly tuning this battlefield until a favorable result appears.
