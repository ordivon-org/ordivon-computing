# PAL Foundations — Wave 4 Foundation Pass

Status: **foundation pass complete; prospective field studies remain open.**

Wave 4 does not close PAL. It takes the six unresolved problems after Wave 3, treats external research and Ordivon's own owner-native evidence as reality pressure on the same epistemic plane, derives a common state-transition model from first principles, and runs only experiments that are identifiable in the current world.

## 1. One problem, six missing transition semantics

The common research state is:

```text
S_t = (
  X_t, current world/task state
  C_t, capability portfolio
  P_t, retained priors/procedures
  G_t, change-generation/application mechanisms
  V_t, evaluation/selection machinery
  L_t, lineage/commitments/evidence/authority continuity
  M_t  mandate/viability/value anchors
)

(S_{t+1}, observations) = T(S_t, W_t, delta_t)
```

The six open problems are places where `T` remains under-specified, not evidence that six new Ordivon layers must exist:

- option value: what in `C_t` should survive before future demand is revealed;
- regulation: what if a change can influence the evidence/evaluator that selects descendants;
- complementarity: what if one change's value depends on other retained changes;
- prior revalidation: when does a retained `P_t` remain applicable after support changes;
- identity under change: which `L_t/M_t` invariants survive implementation/mechanism change;
- pressure selection: how research pressure is derived relative to `M_t` from mismatch/opportunity in `W_t`.

The first-principles contraction is:

> PAL is controlled state transition under uncertainty. `persistent`, `recursive`, `general`, `open-ended`, and `self-improving` are descriptors, not intrinsic value functions.

## 2. External pressure changed the option-value model

Classical real-options work motivates waiting when irreversible commitment and future information matter. But the same family of reasoning does not imply universal conservatism: R&D/experimentation can become more attractive under uncertainty when the activity itself resolves uncertainty. Value-of-information research similarly treats learning as valuable only through the future decision it changes.

Therefore Wave 4 rejects a single option-retention score as the starting point. Relevant dimensions include:

```text
carrying cost
reacquisition cost / delay
reversibility
future workload
blocked outcome
information generated by experimenting
maintenance / compatibility risk
retained complements
```

### F14 — prospective option portfolio: OPEN


No owner capability is installed or removed for the experiment. Only post-cutoff owner-native work or external/provider change can generate a demand event. After a real missing-capability demand, reacquisition cost/delay is measured then rather than imagined in advance.

This upgrades F11 from `did the model predict the later label?` to `what regret did each frozen policy actually cause after the future world was revealed?`

## 4. Regulation now has an identifiability condition

External reward-tampering, proxy-over-optimization and performative-prediction work all share one causal issue: an adaptive action can alter the signal by which later behavior is judged.

The minimum regulation experiment therefore requires:

```text
candidate can influence future evidence/evaluator
AND
proxy can diverge from independent consequence truth
AND
unregulated baseline sometimes retains a false local winner
AND
an independent evidence / rollback arm is feasible
```

### F16 — NOT ADMITTED

Computing's three-generation Continuous Experiment Loop already separates candidate from grader/workload/metric/observation mapping, hides holdout truth from the candidate, rejects same-model self-score as sufficient, blocks promotion on evaluator disagreement, and rehearses rollback.

This proves bounded regulated self-reform can work, but it does not identify the marginal value of regulation because no natural unregulated false self-reinforcement event exists in the current loop.

The wider Computing audit also found no current live loop where a candidate naturally owns the evaluator that selects it. Security's coevolution/evaluator-attack research contains the right future pressure, but the strategic contest unit is not yet admitted.

Wave 4 therefore refuses to remove CEL safeguards or inject a synthetic reward hack merely to make regulation look useful.

## 5. Pressure selection is not value creation from nothing

External open-ended and autonomous-science systems repeatedly automate a bounded version of the problem:

- goals/challenges are generated or selected inside a supplied goal/environment space;
- performance, learning progress, regret, benchmarks, or scientist-provided objectives supply pressure;
- diversity and transfer preserve stepping stones;
- downstream experiment remains the truth boundary.

This is consistent with Ordivon's C6 negative result. C6 asked models to classify/select owner pressure under either a tiny inspection budget or one full-context packet. The selective arm entangled question formation with guessing which owner to inspect; the full arm still missed the Harness shared pressure and produced one Finance false promotion.

The first-principles target is narrower:

```text
mandate / viability anchor
+ observed world mismatch or opportunity
+ causal mechanism hypothesis
+ uncertainty
+ decisive probe
+ expected decision change
+ cost / reversibility
+ failure update
= candidate pressure certificate
```

## 6. Prior revalidation received a natural positive

Continual-learning and change-point research supplies strong pressure against assuming stationarity or universally positive transfer. The more precise first-principles object is not age but the support that made a prior applicable.

Represent a prior as:

```text
K = (
  claim,
  mechanism,
  support conditions,
  evidence family,
  scope,
  falsifier,
  negative-transfer boundary
)
```

A revision/model/task/environment change creates review pressure only when one or more support conditions are plausibly threatened.

### F18 — scoped positive

A natural owner shift appeared after the old Computing Skill-compilation falsifier. Harness subsequently added:

1. explicit installed -> Run-admitted -> turn-admitted capability composition truth;
2. externally evaluated/promoted exact reusable procedural cognition across Runs;
3. bounded ToolProgram composition that reduced the maintained repository-repair workload from 7 model calls to 2 while preserving the same 5 physical Tool calls and per-effect evidence/UNKNOWN boundaries.

This does **not** make the old P3 experiment false. Instead it splits the retained prior:

- `procedure role != correctness or Tool authority` remains valid and stronger;
- `no generic Skill repository/runtime/marketplace` remains valid and stronger;
- the rejected P3 recovery Skill remains historically rejected;
- the broad clause `capability compilation remains unproven` is now too coarse and must narrow to generic learned semantic Skill compilation with demonstrated cross-task decision value.

So both simple policies fail:

```text
expire-all on revision/age  -> deletes valid clauses
keep-all unchanged          -> preserves an overly broad clause
```

Support-bound revalidation best explains the current evidence. No TTL or automatic prior engine is authorized.

## 7. Identity under implementation change received a real migration test

Event-sourcing/schema-evolution work shows why historical evidence and current representations need explicit evolution rather than silent reinterpretation. Harness itself supplied a natural PAL case because the current implementation has mechanisms that did not exist in an older revision.

### F19 — scoped positive

A real no-Tool Harness Run was created under old revision:

```text
321ce5c006b6a28a9f44055688e66d0c3b6b8c09
```

It reached `needs_input` and left a healthy durable paused state.

The exact old-written bytes were then reopened with current revision:

```text
6639cf575eb006e8be2864037d9427b9913dd8a3
```

Current package-level capability truth contained the newer reusable-knowledge topology and ToolProgram mechanism. But the old Run retained exactly the same:

```text
Run ID
Contract digest
Tool catalog digest
Tool grant digest
```

The current Run projection remained `harness.execution.no-tool.v1`; the resumed turn exposed only `conclusion`, no ToolProgram and no Tools. The same durable Run then completed successfully and Doctor remained healthy.

This rejects three simple identity models in this case:

```text
byte sameness       — implementation changed but identity survived
reset everything    — old state reopened and continued directly
inherit everything  — newly installed mechanisms did not become old authority
```

The scoped winner is **invariant-bound continuity**:

```text
preserve by default
  lineage / work identity
  immutable commitments
  already-admitted authority
  evidence and uncertainty history
  owner/participant constraints

replace or migrate explicitly
  implementation
  model/provider
  representation/schema when equivalence is proved
  planning method
  newly available capabilities
```

Implementation evolution may expand what can be admitted next, but it must not silently rewrite what an existing durable object already meant or what authority/effect history it already had.

A second migration family involving schema meaning or owner responsibility is required before stronger promotion.

## 9. What the remaining RSI gap now looks like

The evidence increasingly distinguishes three layers:

```text
1. Adaptation execution
   given a bounded problem, generate/test/retain a change
   -> already strong in several Ordivon loops

2. Adaptation governance
   prevent false reinforcement, preserve identity,
   revalidate old priors, assign interactional credit
   -> partially characterized, still uneven

3. Pressure formation
   discover which mismatch/opportunity deserves the next expensive probe
   relative to real mandates and world state
   -> still the deepest unproven frontier
```

The strongest current interpretation is not that RSI requires a magic self-improvement module. It requires the adaptation operator itself to become better at **forming, discriminating, governing, and capitalizing reality-grounded changes without losing continuity or becoming self-confirming**.
