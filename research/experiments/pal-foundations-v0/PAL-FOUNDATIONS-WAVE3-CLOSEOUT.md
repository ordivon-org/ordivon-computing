# PAL Foundations — Wave 3 Closeout

Status: **Wave 3 complete. PAL Foundations remains open.**

This document closes the current Computing research wave, not PAL as a subject and not an Ordivon reform programme. No Runtime, Host, Harness, World, Workstation or domain owner change is authorized by this closeout.

## What Wave 3 attacked

Wave 3 took three open problems from `hypothesis-map-v1.json`:

1. **Option value** — can a capability with no current use still deserve retention because it changes the future reachable set?
2. **Complementarity / interactional credit** — can two changes have weak marginal value but large joint value?
3. **Prior bias / revalidation** — can retained learning become harmful after model/task change, and can an untuned expiry/revalidation mechanism be tested now?

## F11 — latent option value is real; generic foresight is not

F11 froze 14 decision-point cases with seven latent-option positives and seven anti-cases. The historical positives came from the pre-existing HD2-N2 latent-option pattern across multiple epochs; the Ordivon holdout included P2 scoped egress, whose later Finance/Workstation consumption occurred only after the P2 decision point.

Two treatments were compared with DeepSeek V4 Flash and Pro across 112 logical slots:

```text
GREEDY_CURRENT
OPTION_AWARE
```

On valid holdout decisions, OPTION_AWARE was directionally better (23/25 vs 20/25), but strict both-valid holdout pairs were only **2 wins / 1 loss / 19 ties**; all pairs were **4 / 3 / 35**. Both treatments had 100% valid specificity on negative controls. More importantly, OPTION_AWARE missed the owner-native P2 scoped-egress positive in every valid run.

The split is therefore:

```text
latent option value can exist                     yes
one generic t0 rule can identify it reliably      not established
```

The hard problem is option discovery/valuation under uncertainty, not simply remembering to “consider optionality.”

## F12 — one real scoped complementarity

F12 reused the current Harness P-C1.11/P-C1.12 substrate without changing Harness. It used a four-arm factorial ablation of:

```text
A = caller-ingress durable promotion
B = current WorkingSet addressability + ordinary transition
```

Across launch-code, endpoint and holdout policy-mode corrections:

| Arm | corrected durable | stale absent current | full closure |
|---|---:|---:|---:|
| none | 0/3 | 0/3 | 0/3 |
| promotion only | 3/3 | 0/3 | 0/3 |
| addressability only | 0/3 | 3/3 | 0/3 |
| both | 3/3 | 3/3 | **3/3** |

Task state remained selected, stale exact evidence remained preserved, and Continuity stayed healthy in every arm. The binary full-closure interaction contrast was **+1** in every case.

This is a genuine marginal-deletion warning: judging either mechanism only by full correction closure would score it zero in isolation even though each owns one necessary partial responsibility.

The scope is deliberately narrow. The interaction is mechanically close to the interfaces being tested, so F12 establishes **Harness-local mechanical complementarity**, not a universal PAL coalition-credit law.

An initial F12 run exposed an apparatus metric bug: earlier WorkingSet-history inspection excludes a stale pin that is still current. The final metric treats “still current” or “present in earlier committed history” as preserved exact evidence. The experiment was rerun from the frozen cases after only that metric repair; the full-closure result was unchanged.

## F13 — not running an experiment is part of the result

A prior-expiry/revalidation follow-up was considered because F5, F6, F9 and F11 all show model/task-dependent prior effects. The candidate task-family audit found no materially distinct workload with all three requirements:

- a prior earned before the target change;
- a natural model/task-family change;
- an independent target oracle that does not reuse F5/F6/F9 labels.

Designing an expiry rule now would therefore tune the treatment to already known failures. F13 was **not admitted**. `f13-disposition-v0.json` records exact reopen conditions.

## What is stable enough for reusable Computing Knowledge

Wave 3 promotion audit admits six conclusions into Knowledge and **zero PAL-specific conclusions into Core**:

1. persistence/availability is a precondition, not evidence of adaptive value;
2. recursive/change depth is descriptive, not a reliable value ordering;
3. retained priors are future decision-boundary interventions and can help or harm;
4. safe responsibility placement is insufficient reason to externalize — observed reconstruction burden matters;
5. explicit variation is not a default improvement mechanism when strong direct generation already covers the causal space;
6. current use and future option value are different dimensions, while prospective option identification remains uncertain.

These are compressed in `knowledge/agents/adaptive-change-capitalization.md`.

## Current world-model change

The strongest contraction after F1–F12 is:

```text
PAL is not
    persist → improve → retain → compound

A more realistic research model is
    candidate change
      ↓
    mechanism / owner fit
      ↓
    actual burden or opportunity
      ↓
    later consumption and causal outcome
      ↓
    prior/representation side effects
      ↓
    interaction with other capabilities
      ↓
    carrying / reacquisition / maintenance cost
      ↓
    retain, narrow, expire, delete, or reopen under uncertainty
```

This still does **not** define a PAL architecture. It defines a better set of questions for the next experiments.

## Next frontier

The next wave should open only when reality supplies a discriminating setup:

- prospective hidden-workload option portfolio;
- endogenous self-reinforcement where Regulation has something real to prevent;
- cross-domain four-arm complementarity with owner-native outcomes;
- naturally stale semantic prior crossing a model/task-family change;
- real migration/self-change requiring inheritance decisions;
- materially new pressure signals for autonomous next-problem selection.

Until then, no owner reform follows from Wave 3.
