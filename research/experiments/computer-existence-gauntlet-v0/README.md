# Computer Existence Gauntlet v0

This program attacks every current Ordivon Computer feature from a removal-first presumption. Age, implementation effort, test count, documentation volume, prior promotion, and architecture naming grant no existence right.

A subject survives only in the narrowest form that protects an independently observable capability or failure better than a simpler owner-local or classical baseline. Historical evidence may remain in Git/evidence while completed apparatus leaves the active path.

## Verdict lattice

The program deliberately has no universal scalar score. Each subject ends as one of:

- `retain` — deletion loses a current capability or protected invariant and no simpler lower owner matches it;
- `narrow` — only a strict subset earns retention;
- `localize` — the responsibility is real but belongs closer to one owner/consumer;
- `archive` — historical evidence matters but active machinery no longer has a current consumer;
- `delete` — no independent loss is observed and no live falsifier requires the structure;
- `inconclusive` — apparatus or oracle cannot support a disposition.

## Universal attack set

Every applicable subject is attacked by: deletion/bypass, strongest simpler replacement, fault or semantic mutation, authority inversion/staleness, recovery/restart, bounded resource pressure, null-action cases, and a second materially different consumer for any claimed shared layer. The checker/evaluator under attack may not define its own hidden oracle.

## Waves

1. **CONTROL** — attack the research control plane: portfolio, map, world-model loop, research method, responsibility map, checkers, conformance gate and CI triggering. Prove that semantic drift is actually detected and the detector is actually invoked.
2. **PROTOCOL** — molecular ablation of every `ordivon-protocol` profile/module against current Host/Harness/Game/World/Security consumers. Released history does not automatically force current-main compatibility.
3. **CONTENT** — compare custom content contract/CLI/templates/fixtures with mature generic tooling plus minimal owner-local metadata; localize or delete any Ordivon-specific layer that protects no unique repeated failure.
4. **RESPONSIBILITY** — re-run deletion/replacement attacks for CR-01..CR-18 using owner-native workloads. Durable principles survive only if lower mechanisms cannot own them. Rejected/default-off concepts are attacked for whether even the active question/negative placeholder is still worth carrying.
5. **ACTIVE-TREE** — remove completed experiment apparatus family-by-family while preserving exact closeouts/evidence/Git archaeology. Measure broken consumers, recovered evidence, files/bytes removed, default discovery noise and gate cost.
6. **METHOD** — compare AFR/CEL/portfolio machinery against a task-local frozen manifest + Git + owner-native tests on materially different experiment designs. Research machinery must beat simple disciplined practice, not merely validate itself.
7. **COMPOSED** — adversarial mixed run with concurrent owner movement, stale docs, Tool drift, UNKNOWN recovery, contradictory evidence and a correct null-action outcome. No component earns survival merely from isolated tests.

No wave authorizes a new daemon, scheduler, registry, ontology, automatic promoter, product merge, or open-ended RSI service.

## V1 closeout

The first full existence gauntlet attacked 47 Computer features. The strongest result is contraction, not expansion: a composed shadow removed 317 current-tree files / 2.246 MB / 54,979 lines plus the 248-line research relation graph, extracted one 143-line live freshness utility, and still passed current Host/Harness/Game consumers, retained protocol contracts, current research authority checks, mixed UNKNOWN/Tool-drift/null-action invariants, CI path coverage, and exact Git recovery.

The global research method also failed its incremental survival rule: it gained one development decision, lost two holdout decisions, and used 2.128x tokens versus a concise frozen task-local manifest. Five independent semantic control-plane mutants survived existing checkers even though the semantic-binding positive control was killed.

The audit therefore does not authorize a new Computer layer. It produces a contraction mainline. Historical evidence stays; historical executable apparatus does not automatically stay. Shared protocol is treated molecule-by-molecule; owner-local responsibilities move only with owner admission. See `existence-gauntlet-v1-closeout.json`.
