# EX2 — World × Finance multi-axis falsification

EX2 tests the representation retained by EX1 against owner-native external-effect and domain-semantic pressure. It does not assume the five-axis model is correct.

The frozen owner-native basis is in `authority-freeze-v1.json`. `causal-units-v1.json` performs the first deletion/existence reconstruction over narrow responsibilities rather than project names.

The initial test compares a strong compact responsibility explanation with an explicit five-axis explanation on unseen cases. Each case is scored independently on:

- semantic choice/judgment;
- durable structural state;
- physical truth;
- external-effect truth;
- sharing disposition.

Axis answers are sets, not a single primary owner. This permits facts such as `WORLD + HOST` for a World-owned typed journal persisted through Host continuity, and `FINANCE_LOCAL + NO_SHARED_MECHANISM` for a domain responsibility that should not graduate globally.

If errors concentrate on distinctions that the five axes cannot express—especially semantic owner vs persistence carrier or multiple independent time authorities—the correct EX2 outcome is to revise the representation rather than tune prompts against the same cases.

## Final closeout

EX2 is closed in [`EX2-FINAL-REPORT.md`](EX2-FINAL-REPORT.md).

The initial five-axis representation was rejected. Question-relative relations became stable for the World × Finance pressure set only after separating state semantics from persistence carrier, native fact from local execution/derivation, semantic home from classical delegation/shared promotion, and semantic judge from native external system. The final World × Finance terminology-invariance gate reached 276/276 exact relation answers.

That local success did **not** justify a global ontology. The final whole-family gate scored 310/324 (95.68%) for the role-pure relation representation and failed its preregistered transfer thresholds. `family-relations-v1.json` therefore remains experiment-local audit evidence rather than canonical family authority.

The retained method is smaller: ask the exact responsibility relation currently uncertain, name its subject, compare against stronger classical/domain baselines, perform deletion counterfactuals, preserve owner-native evidence, and state explicit negative proof boundaries. Public and Agent-facing explanations may remain compact natural language when they reconstruct those facts; relation jargon is not a product requirement.
