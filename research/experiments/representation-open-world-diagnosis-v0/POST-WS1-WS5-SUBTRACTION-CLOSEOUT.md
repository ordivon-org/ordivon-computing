# Representation Capability Program — Post-WS1–WS5 Subtraction Closeout v0

Status: **research synthesis candidate**, 2026-08-25. No owner-native semantic files are modified by this detached workspace.

## 1. What the programme originally expected

The programme began with a strong possibility:

`Media × SCD × Harness -> Representation becomes intelligence capability`

and investigated whether representation changes search, hypotheses, action, error detection, recovery and long-term capability under Same Agent / Same Reality / Same Tools controls.

After five workstreams, the main result is not a larger Representation theory. It is a **contraction**.

## 2. What mature external theory already owns

### Representation/computation

External cognition, cognitive fit, knowledge compilation, problem reformulation, data-structure/query complexity, epistemic action and representation-change theory already establish that informationally similar representations can induce very different finite computational costs/search geometries.

### Human-machine work/interface

Cognitive Work Analysis / Ecological Interface Design already joins work-domain constraints, interface representation, perception/action mappings, operator competencies and control. Therefore `domain constraints + observer encounter + action affordance` is not a novel Media×SCD×Harness decomposition.

### Capability

Planning/control/strategy, generalized planning, bounded rationality, transfer and philosophy of ability already distinguish point success, family ability, situated support, robustness and transfer. Ordivon CP/World cover the formal/actual owner-specific forms.

### Lifecycle/resources

Multiobjective/Pareto optimization, amortized complexity, hard/soft constraints, tail risk and human automation literature already handle non-scalar resource/burden trade-offs.

### Diagnosis/recovery/adaptation

Model-based diagnosis, active diagnosis, diagnosability, fault tolerance, resilience, model invalidation, open-set recognition, reject option and open-world adaptive agents already cover competing causes, active discrimination, unknown faults, recovery/degradation and model adaptation.

Generic theory novelty is therefore heavily subtracted.

## 3. What Ordivon owners already own

- **World** — boundary-/transition-/condition-relative actual Capability, Option/substitution/redundancy/current support, recovery evidence boundaries.
- **Computational Possibility** — regime-relative witness/strategy achievability, uniformity, discoverability, resource vectors/preorders, robust/recovery obligation shapes.
- **Verify / Track R** — competing hypotheses, failure attribution, evaluation/replay, independent verifier, explicit UNKNOWN, causal comparison of model/Harness/Context/Tool/environment contributions.
- **SCD** — judgement-relative semantic description, preservation/substitutability, anti-collapse/non-entailment and semantic evolution.
- **Media** — structured observer mediation / artifact-observer encounter, not underlying source truth.
- **Harness** — bounded Agent Run mediation, Context/tool exposure, use-relative Context substitution, OPUR reconfiguration preservation, reconciliation/recovery mediation.
- **Host** — research/task semantic continuity, not evidence truth.
- **Runtime** — physical execution/Job/Artifact truth, not semantic completion.

This owner map absorbs most candidate new Representation primitives.

## 5. What is still genuinely useful about Representation as a research object

Representation remains useful because interventions can alter a finite observer/system while source truth and model weights remain fixed.

But every experiment must ask **what changed** rather than use `representation` as a causal black box.

Useful intervention signature:

- source/evidence set changed? -> information intervention;
- semantic distinctions/entailments changed? -> semantic representation intervention;
- locality/order/salience/navigation changed? -> encounter/search-geometry intervention;
- notation/operators/preconditions/constraints changed? -> operational-grammar intervention;
- callable tools/environment/process changed? -> representation-coupled environment intervention;
- filtering/state/recovery responsibility moved? -> allocation/support intervention;
- preprocessing/compiler/advice added? -> charge it explicitly;
- authority/currentness changed? -> not equivalent capability unless target permits it.

No universal schema is required; this is an experiment checklist only when the distinction is load-bearing.

## 6. G/R/A after contraction

### G — Encounter Geometry

Retain strongly as a causal mechanism family for locality, position, salience, grouping, navigation and change visibility.

### R — Operational Grammar

Retain cautiously as a mechanism family for notation, transformation rules, invariants, preconditions, admissible/invalid operations and action semantics.

### A — Responsibility Allocation

Retain most cautiously. It describes where filtering, computation, state maintenance, monitoring and recovery responsibility sits across actor/artifact/tool/time, but risks becoming a catch-all. Every A claim therefore requires a concrete intervention/deletion witness.

The three are **not canonical axes** and need not be exhaustive/minimal. They remain lightweight repair/search vocabulary pending a natural prospective holdout.

## 7. The strongest Representation-specific methodology that survived

A valid Representation causal claim now requires a chain roughly like:

`owner-qualified source`
`-> frozen target/judgement`
`-> declared representation intervention signature`
`-> semantic admissibility where required`
`-> exact observer/Run/tool/environment realization`
`-> outcome/error/recovery evidence`
`-> competing causal explanations`
`-> owner deletion / direct controls`
`-> consequence and later recovery/currentness check`

This is not a Representation engine. It is **owner-preserving causal discipline**.

## 8. Why the original Media × SCD × Harness COJC is weaker after research

### Joint explanation

Strong. The responsibilities are naturally distinct:

- SCD: may this representation lawfully stand in for source meaning for judgement Q?
- Media: how does this observer encounter/navigate/operate on the artifact?
- Harness: what representation/tool/action surface actually enters this bounded Run and survives reconfiguration/recovery?

### Joint operational composition

Strong. They can compose without transferring source ownership.

### Joint capability

**Still unproven and now harder to claim.**

Reasons:

1. external EID/CWA already demonstrates constraint-to-interface-to-action compositions without this owner decomposition;
2. SCD may be adjudicative only if source-owner semantics suffice;
3. Media may add no value beyond generic task-fit information architecture;
4. Harness may be a carrier if direct Provider/source controls realize the same treatment;
5. open-world failure attribution additionally requires source/World/domain truth and Computing/Verify research authority, so the triad is not a causally closed unit;
6. no materially different natural workload has yet shown all three owners deletion-essential.

Therefore the current evidence supports `JOINT_EXPLANATION + OPERATIONAL_COMPOSITION`, not `JOINT_CAPABILITY`.

## 9. The one high-potential seam still worth waiting for

The narrowest plausible deletion-positive seam is:

`SCD-qualified domain-semantic preservation`
`×`
`Harness use-relative substitution / OPUR reconfiguration`

under a natural workload where:

- an Agent representation/context/tool support must be replaced/reconstructed;
- Harness U includes a domain-semantic obligation Harness cannot own;
- a tempting fallback is operationally available but semantically unsafe (e.g. loses UNKNOWN/non-entailment/currentness distinction);
- source-owner semantics alone do not provide an equally cheap/clear preservation discriminator;
- deleting SCD qualification changes actual recovery/decision outcome;
- deleting Harness reconfiguration semantics changes actual bounded Run/recovery outcome.

Media becomes causal only if observer encounter mediation is also independently deletion-essential; do not force it into this seam.

No synthetic workload should be built merely to prove this candidate.

## 10. New center of gravity

The initial slogan:

`Representation may be intelligence capability`

should be replaced by the narrower statement:

> **For finite observers, representation is one way computational/search/operational responsibility is distributed across observer, artifact and environment. This can materially change situated system capability, but the capability itself remains target-, boundary-, resource- and environment-relative; representation-specific causal credit must be established by controlled intervention and competing explanation.**

The harder practical problem is no longer representation optimization. It is:

> **When is representation actually the causal bottleneck, and which smallest semantically lawful, observer-appropriate, operationally realizable intervention improves the named target without creating hidden lifecycle/recovery debt?**

## 11. False-positive map

- more evidence mistaken for better representation;
- compiler/precomputation mistaken for representation-alone intelligence;
- Tool/action-surface change mislabeled static representation;
- prompt/Harness elicitation gain mislabeled model-internal capability gain;
- one budget-point speedup mislabeled new capability;
- training-fit performance mislabeled family/uniform operator capability;
- immediate use gain mislabeled persistent recovery gain;
- stale compiled view mislabeled cheap equivalent capability;
- multiple correlated representations mislabeled redundancy;
- successful compensating representation mislabeled root-cause proof;
- Human cognitive mechanism transported to Agent without evidence;
- owner participation mislabeled causal contribution;
- generic HCI/task-fit formatting mislabeled Media-specific capability;
- semantic adjudication mislabeled SCD causal capability;
- Harness carrier behavior mislabeled Harness causal capability;
- retrospective G/R/A explanation mislabeled prospective diagnostic theory.

## 12. Natural evidence gates from here

Do not create more representation services, schemas or synthetic matrices.

Wait for two independent kinds of natural pressure:

### N1 — ANC-REPRESENTATION operation-relative workload

A materially different natural research-audit workload can test whether source-bound operation-relative projection reproduces useful value beyond full source/generic representation.

### N2 — ambiguous natural failure/recovery

The dormant `NATURAL-PROSPECTIVE-HOLDOUT-CONTRACT.md` tests whether set-valued owner-qualified diagnosis avoids false representation causal promotion and improves repair/mitigation decisions.

A third future seam (semantic substitution/recovery) activates only if an actual reconfiguration creates the SCD×Harness obligation-preservation pressure described above.
