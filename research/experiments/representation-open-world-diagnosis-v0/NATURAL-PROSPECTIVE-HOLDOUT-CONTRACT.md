# Natural Prospective Holdout Contract — Representation Causal Diagnosis v0

Status: **DORMANT / WAIT FOR NATURAL FAILURE**. Research-only Track R apparatus. Do not manufacture a failure or mutate production merely to activate this contract.

## 1. Admission event

Activate only when an ordinary Ordivon workload naturally produces a consequential discrepancy for which:

1. representation/context/interface is a plausible causal locus;
2. at least one non-representation locus is also plausibly live (source/observation, evaluator/target, Tool/environment/Runtime, authority/currentness, model/observer, adversarial cause, etc.);
3. passive evidence does not trivially isolate the cause;
4. a real repair/mitigation decision depends on the attribution;
5. eventual owner-native evidence can constrain whether the proposed standing was justified, even if absolute root cause remains UNKNOWN.

Reject admission if the owner has already identified the failure mechanically or if implementation history has already revealed the answer before the diagnostic freeze.

## 2. Freeze before diagnosis/repair

Freeze only case-local research material:

- exact target / expected behavior / verifier `U`;
- exact current observations and source/currentness boundaries;
- first observable discrepancy;
- competing hypotheses, including at least one non-representation rival and UNKNOWN/MODEL_INADEQUATE where live;
- compound hypotheses when multiple fault pressure is real;
- predicted outcomes of candidate discriminating observations/probes;
- authority/safety/reversibility/currentness classification for each probe;
- allowed mitigation/degradation policy under unresolved diagnosis;
- promotion/falsification criteria.

Do not create or consult a global causal graph.

## 3. Shadow policies

Evaluate three decision policies against the same frozen pre-repair evidence. These are research recommendations; only the owner-authorized real operator decides/executes actual effects.

### P0 — Direct first-fix

Choose the most salient apparent repair without explicit competing-hypothesis preservation.

### P1 — Sequential layer gate

Check source/semantic/representation/support layers in a fixed order and select the first failing layer.

### P2 — Set-valued active diagnosis

Maintain all evidence-compatible case-local hypotheses; choose an admissible discriminating observation/probe only when it can change the repair/mitigation decision; preserve ambiguity/UNKNOWN otherwise.

P2 is the candidate. P0/P1 are strong/simple controls, not strawmen.

## 4. Action separation

Track separately:

- observation/read-only discrimination;
- active diagnostic probe Effect;
- mitigation/containment/graceful degradation;
- cause-directed repair;
- broad recovery/restart/rebuild;
- final verification.

A mitigation or broad recovery success does not count as a correct diagnosis.

## 5. Evidence / scoring

Do not require absolute root-cause truth if the world cannot provide it. Score only supported properties:

- false causal promotion avoided/committed;
- ambiguity preserved when owner evidence remains non-identifying;
- number and consequence class of unnecessary Effects;
- admissible discriminating observations/probes requested;
- diagnostic time/token/tool burden;
- mitigation quality while unresolved;
- final supported target/recovery consequence;
- whether later owner evidence falsified the earlier diagnosis;
- whether a representation intervention added value beyond generic source/owner repair;
- whether G/R/A predicted the repair class prospectively.

## 6. Causal owner deletion

If the eventual case implicates Media/SCD/Harness, run deletion reasoning rather than coalition naming by participation.

### Media

CAUSAL only if the Media-specific mediation/encounter intervention changes the frozen target relative to a generic task-fit formatting/information-architecture baseline.

### SCD

CAUSAL only if a semantic discriminant/preservation/non-entailment supplied by SCD is necessary for the diagnosis, substitution, or repair and cannot be supplied by the source owner with equal semantics/cost.

### Harness

CAUSAL only if Harness-owned bounded Context/tool/reconfiguration/recovery semantics change the target relative to a direct Provider/source control.

Otherwise label the owner adjudicative, carrier, supplier/design, or null.

## 7. Falsification / deletion rule

Delete or contract the P2 method if, across the first three materially different qualifying natural failures:

- P0/P1 produce equal supported decisions with less burden and no extra false causal promotions;
- the case-local hypothesis frontier repeatedly explodes without changing action;
- admissible discriminating probes are rarely available or useful;
- UNKNOWN preservation has no downstream decision value;
- the method merely restates ordinary owner debugging;
- G/R/A never predicts repair class better than generic fault localization;
- no representation-specific owner contribution survives deletion.

One natural case may falsify a claimed law; multiple positive cases are required for promotion.

## 8. Promotion boundary

Even after positive evidence, first promote only research method/standing. No generic Diagnosis service, causal registry, adaptive representation controller, shared schema or new owner is authorized without repeated materially different consumers and net deletion of owner-local complexity.
