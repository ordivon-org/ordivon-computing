# OFR0–OFR2 — Foundations Reconstruction Archaeology

## Scope

This is a **research-only** archaeology round. It does not revise `core/` or `knowledge/`, does not move owner-native truth into Computing, and does not create a theory registry/service.

The unit of analysis is not a file. It is a **recoverable generative claim**: a claim with enough lineage, scope, falsifier/negative boundary and engineering consequence to explain or predict a decision.

## Frozen boundary

`owner-freeze-v1.json` binds current Git owner heads for Computing, Host, Runtime, Harness, World, Human, Finance, Workstation, Security, Game, Studio and Web. Host semantic checkpoints and historical experiment commits remain evidence/history; they do not override current owner Git. Any later owner change is post-freeze evidence.

## Method

```text
current owner truth + Host semantic history + retained research evidence
→ OFR0 theory-asset census
→ OFR1 debt map
→ OFR2 convergence families
```

OFR2 grades convergence instead of counting similar words:

- **A** — strong independent convergence under materially different owners/failures/mechanisms;
- **B** — real owner-specific reproduction with plausible shared architecture/research ancestry;
- **C** — provisional resemblance/transfer hypothesis, not independent validation.

For every convergence family, `independent-convergence-v1.json` records an anti-pseudoreplication argument, transport boundary and strongest current falsifier.

## Non-goals

- no “Grand Unified Ordivon Theory”;
- no scalar theory/debt score;
- no promotion into Core from this round alone;
- no vocabulary normalization that erases owner semantics;
- no preservation of dead experiment apparatus merely for narrative completeness.
