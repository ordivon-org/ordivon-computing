## Grade A — strongest current convergence

### C1 — Non-rewriting Temporal Truth

Finance, Security, Workstation and Runtime/Host arrive from different failure classes at the same semantic requirement:

```text
current projection may change
!=
historical event/admission/knowledge was rewritten
```

The shared claim is strong; the mechanisms must remain separate. `effective time`, `observed_at`, authority revision, network generation and Task revision are **not** one universal clock.

### C2 — UNKNOWN Is a First-Class Action State

Runtime duplicate-effect recovery, Finance identity/carrier uncertainty, World evidence actionability, Security evidence/authority currentness and Human review all need unresolved states because they imply different next observations/actions. This is more than a stylistic preference for uncertainty.

### C4 — Invariant-Bound Identity

Run identity, financial instrument identity, network path/generation, authority identity and Runtime operation identity independently reject “same label/bytes/revision = same semantic object”. The shared question becomes: **which invariants are non-bypassable for this owner?**

### C5 — Evidence Availability ≠ Knowledge/Promotion Authority

World R8, Human Promotion Gate and Harness reusable cognition independently place an admission boundary between “we have evidence/cognition” and “future systems may treat this as stable reusable authority”. This is one of OFR2's strongest candidates for later Knowledge synthesis.

## Grade B — real recurrence, shared ancestry must be discounted

Projection≠authority, capability≠authority≠consequence, contraction, recoverability, option value, lawful stopping and semantic-without-mechanism convergence all have real owner evidence, but Computing/Core methodology plausibly helped generate the language or experiment. They should be retained as **supported shared priors**, not celebrated as independent rediscoveries.

## Grade C — deliberately not promoted

`C9 Consumer Pressure Determines Layer Admission` currently remains Grade C. Game gives strong evidence, Web/Studio give compatible cases, but these domains recently consumed the same Computing methodology. The correct next evidence is an independently pressured Studio/Web/Finance/Security failure, not another essay explaining why the rule sounds right.

## Anti-unification result

OFR2 repeatedly finds this shape:

```text
shared semantic inequality
+ different owner mechanism
+ different currentness/authority/recovery law
```

Therefore the convergence map itself is evidence **against** a universal `TheoryService`, `EvidenceManager`, `IdentityGraph`, `CurrentnessService` or cross-domain state machine. The strongest common object is often a *question or inequality*, not an implementation.
