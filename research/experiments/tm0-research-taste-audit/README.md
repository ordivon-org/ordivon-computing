# TM0 — Research Taste / Tractability Audit

TM0 asks whether Ordivon's recurring research choices already imply a stable set of probabilistic world-model priors about productive inquiry.

The object under study is **not** a new scheduler, scoring engine, meta-reasoning framework, or universal research policy. It is the compressed set of conditional claims that repeatedly help an Agent transform a broad question into a bounded, discriminating, affordable experiment.

The audit separates three layers:

- **semantic laws** — distinctions whose collapse produces category errors, such as the WL0 laws;
- **research-taste priors** — probabilistic claims about which question transformations are likely to produce information efficiently under current resources and world dynamics;
- **constitution / architecture principles** — chosen normative boundaries such as scoped authority and no automatic centralization.

Files:

- `TM0-AUDIT.md` — evidence-backed qualitative audit and current gaps;
- `taste-priors-v0.json` — machine-readable candidate priors, rejected anti-priors, tractability dimensions, and question-transformation operators.

TM0 is intentionally retrospective and research-only. It does not claim calibrated probabilities, does not rewrite `core/foundations.md`, and does not promote a Tractability Engine. A future prospective experiment would be required to test whether these priors improve actual question selection versus a strong simpler baseline.
