# OFR0–OFR7 Foundations Reconstruction — Programme Closeout

## Status

**COMPLETE. The reconstruction programme is closed as an active research line.**

The programme began with a concern that Ordivon's theory existed implicitly but was poorly organized. The final answer is narrower and more useful: Ordivon already possessed a thin generative Core and many owner-local causal invariants, but the **causal derivation and negative knowledge behind them were easier to lose than the implementation itself**. OFR0–OFR7 repaired that asymmetry without creating a central Theory product.

## What the programme actually changed

Across the six programme commits, Git records **71,934 insertions / 9 deletions**. Against that research/evidence volume, the net durable `core/ + knowledge/` mutation from the pre-OFR base to `b29c553` is only **85 insertions / 9 deletions across 4 files**. Durable doctrine insertions are about **0.12%** of programme insertions.

That ratio is itself evidence of successful contraction:

```text
large search / experiment / failure surface
→ small retained causal invariants
→ almost no Core growth
```

No A19 was added. `core/foundations.md` remains exactly A0–A18. OFR6 only sharpened A10's UNKNOWN boundary and the primitive Contract's invariant-bound identity rule; OFR7 added no Core text.

## Final architecture

The programme closes on four different persistence levels:

```text
Core
  smallest generative constraints
  A0–A18

Knowledge
  reusable causal distinctions, examples, boundaries, negative knowledge

Owner-local evidence
  exact current contracts + causal histories + implementation-specific falsifiers

Research/Git history
  open hypotheses, failed representations, apparatus, frozen campaigns
```

The important separation is that **shared explanation does not acquire owner truth or mechanism authority**. A shared Foundation may explain why an owner boundary exists; only the relevant owner establishes current fact, identity, permission, admission, or consequence.

## What survived

### Core refinements

1. **UNKNOWN non-collapse** — missing/stale/conflicting/insufficient evidence remains an explicit action-relevant unresolved state when collapsing it would change the next action.
2. **Invariant-bound identity** — identity follows owner-named meaning-bearing invariants; labels, bytes, names/tickers and implementation revisions alone are neither necessary nor sufficient.

Everything else from the 18-candidate court either independently supports existing A0–A18, belongs in Knowledge, or stays Research.

### Knowledge that is now reusable

- current use, option value and capability value are distinct;
- the current winner is not the whole causal theory: defeated attractive rivals and decisive falsifiers may need to remain recoverable;
- a reopen condition is not evidence that the condition occurred and is not action admission;
- navigation/indexes are not causal truth or current owner truth;
- mechanically known currentness/truth-role/authority facts should be projected rather than repeatedly regenerated from prose when the owner actually knows them;
- compression is receiver-conditioned and measured over the whole accepted-work loop;
- **Foundations are reconstruction/transfer priors, not default per-decision Context.**

### Owner-local causal capital

The exact OFR3 histories for Runtime, Host, Harness, World, Human, Finance, Workstation, Security, Game and Web remain owner-local. This is intentional. Copying them into a central theory corpus would reduce currentness and blur responsibility. Shared doctrine retains only the implementation-independent intersections that survived cross-owner evidence.

## What was explicitly killed

The programme should be judged partly by what it prevented from becoming architecture:

- winner-only causal summaries;
- a universal minimal-chain/causal-kernel packet;
- a TheoryDB / TheoryService / theory registry / rule engine;
- an INDEX_ONLY theory surface;
- centralized shared laws as replacements for owner-local causal history;
- two-call ATLAS_PROGRESSIVE as a product;
- model-selected per-role hydration as a default public abstraction;
- eager full-Foundations injection into every bounded Agent decision.

These remain historical evidence where useful. They are not active compatibility promises.

## Apparatus contraction

OFR4–OFR7 runners, packet forms, Atlas surfaces, advisory panels, frozen corpora and diagnostics remain in Git because they make the evidence reproducible. They **leave active attention now**.

Do not keep rerunning them to manufacture confidence. A completed fixture reopens only when a named falsifier, new model/consumer, or changed owner reality makes the old result decision-relevant again.

This is the same distinction the programme discovered elsewhere:

```text
historical reproducibility
!=
active operational burden
```

## Default consumption rule after OFR7

```text
1. Fetch / receive exact owner-current facts.
2. Ask whether those facts already expose the decisive distinction.
3. If yes: use them directly.
4. If no: load the smallest relevant Foundation / Knowledge.
5. If shared Knowledge is still insufficient: hydrate exact owner-local causal evidence.
6. Revalidate present truth with the owner before consequential action.
```

The world model should therefore **shape representation selection**, not maximize world-model text inside every Context.

## What remains genuinely unresolved

Only three frontiers survive this programme as research rather than hidden commitments:

1. **Foundation discovery/selection under missing distinctions.** OFR7 made answer-enabling facts explicit, so it cannot tell us whether shared theory helps when the Agent must first discover what causal distinction or owner evidence is missing.
2. **C9 consumer-pressure descent.** The intuition is strong, but independent evidence remains weak/Grade C; A13 burden-before-layer is the retained Core rule.
3. **M18 hydration granularity.** Complete case hydration beat role-level selection in OFR5's environment, but that remains consumer/model specific.

None justifies OFR8 automatically.

## Reopen contract

Reopen Foundations reconstruction only if reality supplies one of these pressures:

- repeated consequential Agent failure because decisive causal structure is absent from direct owner facts;
- repeated expensive archaeology because owner-local negative causal history cannot be recovered;
- a genuinely unowned cross-owner responsibility whose local duplication causes measured drift/cost and whose deletion breaks multiple workloads;
- independent replication that upgrades C9 or M18;
- owner evidence that directly contradicts a retained shared claim in scope.

Otherwise the correct action is **consume the results, not continue the programme**.

## Final judgement

OFR0–OFR7 did not discover a larger Ordivon theory. It discovered why the current theory should remain small.

The durable outcome is:

```text
Reality / owner truth
→ evidence
→ causal reconstruction
→ shared invariant only when independently earned
→ thin Core + richer optional Knowledge
→ task-specific Context selection
→ action
→ new reality pressure
```

This closes the reconstruction loop without closing the world model: future reality can still falsify any retained claim, but no Foundations-specific active line remains merely because more theory could be written.
