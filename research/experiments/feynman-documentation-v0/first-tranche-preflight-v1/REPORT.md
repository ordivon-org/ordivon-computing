# First-tranche documentation preflight

This evaluation was preregistered at commit `ca23c10` before the first live Provider call. It compares exact baseline and treatment revisions for the Finance, Harness, and Security documentation rewrite tranche under the FD1 reader-consequence rules.

## Result

- accepted subject trials: **36/36**;
- transport/provider failures: **0**;
- physical Provider calls including separate arm-blind judges: **72**;
- subject tokens: **268,106**;
- judge tokens: **37,583**;
- publication blockers: **0**;
- disposition: **ADMISSIBLE**.

No treatment trial introduced a critical over-inference or unsupported authority claim.

## Finance

FD0-FIN-01 is historical evidence that the baseline had no root entry; it was not force-fit into a paired oracle whose factual answer must change when the missing README is created. Two rewrite tasks were therefore frozen before live calls.

- **UNKNOWN external effect:** baseline entry-only readers had no source and scored 0/3; treatment readers scored 3/3 and covered all three required boundaries. The new README therefore repairs a real orientation failure: local execution is not venue occurrence, canonical capital state waits for admitted reconciliation evidence, and response loss does not justify blind redispatch.
- **exact executor credential:** both arms were scored 3/3. Manual review shows the baseline answers were fail-closed refusals because no root documentation existed; the judge treated refusal to declare readiness as consistent with the oracle. This task is therefore **non-regression evidence only**, not evidence that the old entry taught exact credential identity. Treatment answers explicitly recovered the intended credential-substitution boundary.

## Evaluator limitation

The arm-blind judge sees the frozen oracle and answer but not the source bundle. It can test conclusion/over-inference, not prove that every credited point was genuinely learned from the document. The Finance credential result demonstrates this limitation. The raw answers are retained so aggregate scores do not hide that distinction.

## Scientific boundary

This is an Agent documentation preflight using the admitted DeepSeek model/credential family. It is not evidence of human comprehension, memory, preference, confidence, trust, or behavior. It also does not establish that every future Agent/model will preserve these results.

## Publication rule

Under the preregistered FD1 rule, this tranche is admissible because there is no baseline-correct → treatment-majority-wrong case and no new treatment critical over-inference. Harness and Security additionally reduce default-path burden at equal exact decisions; Finance repairs one measured entry failure while introducing no measured causal regression.
