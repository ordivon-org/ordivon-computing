## What happened to the seven FD1 disciplines?

The first tranche did **not** justify adding a new universal rule. All seven survive, but three were too weakly stated. `editorial-discipline-v2.json` therefore keeps the same seven and strengthens only their failure boundaries.

1. **Choose reader job — retain.** The Harness foreign-markdownlint incident showed that a rule useful to Computing reference/managed docs is not automatically an owner-wide semantic gate.
2. **Lead with pressure/judgment — retain.** Finance's measurable 0/3 → 3/3 entry improvement came from adding the missing causal entry, not from creating more metadata.
3. **Name actor/owner/scope — retain.** All Harness/Security treatment answers preserved the intended authority boundaries after large compression.
4. **Show one causal journey — retain.** Finance response loss and Security consequence admission allowed substantial inventory deletion without losing the operational model.
5. **Current before target before history — strengthen.** Correct prose at revision A is not current prose after owner A begins a materially different contraction. Publication must revalidate currentness, not merely Git ancestry.
6. **Layer detail and link authority — strengthen.** Linking instead of copying worked for Harness/Security, but Finance showed that a link itself can go stale when the owner deletes the linked authority. Links create review obligations, not timeless truth.
7. **Route/test by reader consequence — strengthen.** FD0-FIN-01 could not be paired because creating the README intentionally changes the factual answer to “does a README exist?”. Stable causal tasks and structural-presence tasks must not be conflated.

## Rejected after dogfood

- No cross-owner markdown style/lint configuration. Harness's owner-native documentation contract passed while Computing's unrelated 80-column/frontmatter-title preferences rejected the same files.
- No word-count success criterion. Compression matters only after causal decisions remain correct.
- No requirement to preserve experiment numbering in the default path merely because the research was expensive.
- No deletion of scoped canonical research evidence to make the entry look clean.
- No forced Finance `main` update through an active dirty owner worktree.
- No human readability claim from the Agent preflight.

## Next boundary

The first tranche is enough evidence to proceed to the next owners **using discipline v2**, but not enough to claim a universal final writing method. Before each owner edit, current owner truth and publication state must be observed again. Finance must be rebased against whatever owner contraction actually becomes current before its candidate can be promoted to `main`; its old-parent candidate must not be treated as a floating latest README.
