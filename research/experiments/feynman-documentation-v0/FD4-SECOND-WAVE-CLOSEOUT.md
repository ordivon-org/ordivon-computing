FD4 applied the Feynman documentation programme to four system-level owners: World, Host, Runtime, and Computing. This wave deliberately differed from FD2–FD3: the starting documents were already technically strong, so the question was whether causal entry paths could improve without turning the project family into a mandatory stack or discarding target-specific evidence.

## What happened to the seven disciplines?

The second wave again failed to justify an eighth universal rule. All seven survive.

1. **Choose reader job first — retain.** Host demonstrates that a successful rewrite can be burden-neutral when the job is orientation/recovery prediction rather than compression.
2. **Lead with pressure and judgment — retain.** World response loss and Runtime local-success/external-UNKNOWN stories replaced large amounts of phase/target detail without losing decisions.
3. **Name actor, owner, and scope — retain.** Every accepted treatment/follow-up reader decision preserved owner/proof/meaning boundaries.
4. **Show one complete causal journey — retain.** A concrete consequence/recovery path was sufficient to move many details behind links.
5. **Current before target before history — retain.** Runtime independently reproduced the Finance failure mode: a fully tested candidate can still be unpublishable while linked owner truth is actively moving.
6. **Layer detail and link authority — strengthen.** Owner-native stable headings/navigation anchors can themselves be interface contracts; preserve them when the owner checker depends on them. Links still create currentness obligations, as Runtime's moving technical docs and Computing's 404 links demonstrated.
7. **Route and test by reader consequence — strengthen.** Correctness remains primary, but at ceiling correctness a material burden increase without decision gain must trigger contraction. Exact transport failure recovery replays only the missing frozen trial; no mass reruns.

These refinements are recorded in `editorial-discipline-v3.json`.

## Rejected after FD4

- treating current project names as an eternal mandatory Agent stack;
- accepting Runtime first draft because it was semantically correct despite higher burden;
- deleting stable owner-native heading anchors for prose aesthetics;
- changing owner checkers to fit the rewrite when the existing public interface is reasonable;
- treating every successful rewrite as a word-count reduction problem;
- preserving dead public links for table symmetry;
- force-publishing Runtime through active owner-current mutation;
- mass-rerunning 47 successful trials after one transport failure;
- inferring human understanding from fresh-Agent reconstruction.
