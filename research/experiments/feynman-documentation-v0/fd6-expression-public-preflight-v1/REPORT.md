# FD6 Studio/Web expression-public preflight

Studio and Web were paired against their exact pre-rewrite revisions using the four frozen FD0 tasks concerned with revision-bound expression, human-response claims, public review obligations, and encounter-versus-comprehension. The contract was committed at `c1a0965e83dc868ab8441b83cb38728f49fe6f95` before any third-wave Provider call.

## Result

- 24/24 accepted reader trials;
- 24/24 independent arm-blind judge results;
- 48 physical Provider calls;
- every baseline and treatment arm 3/3 decision-correct;
- zero critical over-inference;
- zero unsupported-authority claims;
- zero failures and zero publication blockers.

### Web

The treatment moves the root entry from technology/deployment-first toward public consequence: owner change creates review obligation, and encounter evidence does not establish human comprehension.

- WEB-01 bundle: 23,693 → 23,193 bytes (−2.1%); tokens: 18,901 → 18,633 (−1.4%).
- WEB-02 bundle: 18,393 → 17,893 bytes (−2.7%); tokens: 15,880 → 15,435 (−2.8%).
- root README contracts from 5,627 to 4,919 bytes (−12.6%).

Both treatments are smallest-non-inferior on the frozen Agent tasks and improve the explicit negative-proof boundary around human response. The evidence does **not** establish that human readers actually understand, remember, trust, or prefer the new surfaces. That remains a separate empirical programme.
