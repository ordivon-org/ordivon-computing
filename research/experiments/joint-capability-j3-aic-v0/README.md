## Question

Can a fresh finite Agent recover an actionable institutional Now under succession, compromise, invalid/valid change, delayed remedy, contested authority, and root compromise more reliably from a deterministic provenance-bound `CurrentBindingFrontier` than from the exact same raw history alone?

Before any model comparison is allowed, the apparatus must prove the narrower mechanical premise:

> histories that are identical under a naïve latest/effective-state projection can require different institutional standings and different safe next actions.

## Owner boundary

- Game / World: occurrence and continuing consequential history.
- Security: effective control, compromise, evidence and recovery facts.
- Normative: power, status, valid transformation and predecessor-relative change.
- Interlocus: binding/currentness/migration/conflict-preserving projection discipline.
- Computing: experiment contract, cross-owner comparison and evaluation only.

Computing does not mint any of the above source truths.

## Stages

### S0 — deterministic semantic falsification

`aic_semantic_falsify.py.txt` preserves the byte-identical closed apparatus that ran paired state-aliasing cases plus randomized property/replay stress. Required gates include:

- lawful succession and credential usurpation can share the same naïve final state while requiring different authority standing;
- valid amendment and physical configuration tamper can share the same naïve final state while requiring different normative rule standing;
- valid sanction and unauthorized coercion can share the same naïve final physical/effective state while requiring different remedy/history standing;
- recovery never rewrites historical occurrence;
- full root-threshold compromise cannot self-mint a sound successor anchor in-band;
- conflicting supported authority claims remain conflict rather than being silently dropped;
- deterministic replay reconstructs the same typed state.

Failure of any mandatory gate stops the experiment before model calls.

## Stop rules

- Semantic apparatus failure -> stop and repair theory/apparatus; no model campaign.
- Raw and frontier arms both solve the holdout without meaningful error difference -> no current representation engineering claim.
- Frontier helps only a weaker model while a stronger model reconstructs raw history reliably -> representation-effect candidate, not owner irreducibility.
