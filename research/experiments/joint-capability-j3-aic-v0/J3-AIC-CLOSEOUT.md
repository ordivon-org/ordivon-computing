# COJC Programme Track J3-AIC — Closeout

Status: **COMPLETE as a bounded synthetic institutional-currentness research track.**

This closeout records the completed evidence chain for Programme Track J3 (`Authoritative Synthetic Institutional World`), specifically the AIC / Adversarial Institutional Currentness branch. **Track name J3 is not the COJC evidence-ladder label `J3 higher-order irreducibility`.** This experiment does not establish Game × Security × Normative higher-order irreducibility, emergence, a phase transition, or a new Institution/AIC owner.

## 1. What survived

The strongest surviving result is not “institutions emerge from three owners.” It is a representation/state/currentness result:

> A finite Agent acting in an institutional world should not be forced to reconstruct actionable Now directly from raw history, but the Agent-facing currentness representation must also not be mistaken for the owner-side transition state needed to process future events.

The resulting architecture is horizon-relative:

```text
owner-native truth/history
        ↓
query-relative continuation slice
        ↓
current binding / set of admissible bindings
        ↓
immediate consequence envelope
        ↓
consumer decision
```

The continuation slice is a virtual product of owner-native state for one query/operation. It is **not** a new central truth object.

## 3. S5A — currentness projection is not transition state

A transition-sufficient abstraction `F` would require, over the admitted event language:

```text
F(h1) = F(h2)  =>  F(h1·f) = F(h2·f)
```

for every common future suffix `f`, relative to the institutional observables under test.

S5A falsified this for Orthogonal Frontier v2 with three targeted counterexample families:

1. exact compromised-root identity can be hidden behind the same current `DEGRADED` standing;
2. one current-support authority claim can be transition-relevant before it creates visible contest;
3. sanction identity/status can be transition-relevant to future review even when current resources/currentness are equal.

Generative test:

- 120,000 histories;
- 149,943 equal-Frontier/common-future checks;
- Frontier counterexample found;
- 149,781 equal experimental-ContinuationKernel/common-future checks;
- no kernel divergence found under the frozen budget.

Registered dispositions:

- `FRONTIER_IS_CURRENT_SUMMARY_NOT_STATE`
- `CONTINUATION_KERNEL_SURVIVES_GENERATIVE_TEST`
- `LATENT_OWNER_STATE_NEEDED`

The experimental `ContinuationKernel v0` is retained only as a falsification device. Architecture interpretation is query-relative composition over owner-native source state, not persistence of one shared kernel object.

## 4. S5B-A — partial-order currentness

S5B-A stopped assuming that event arrival order is authoritative. A concurrent batch was interpreted through all unique admissible sequentializations, producing a set of current binding results and a set of continuation results.

Across 50,000 synthetic concurrent batches under the frozen generator:

- `DETERMINATE`: 86.47%;
- `VISIBLE_BINDING_AMBIGUITY`: 11.37%;
- `LATENT_CONTINUATION_AMBIGUITY`: 2.16%;
- action-relevant ambiguity: 9.7%.

These rates are generator properties, not real-world frequencies.

The important structural result is:

```text
unique Agent-facing current binding
!=
determinate future transition state
```

because some unknown orderings collapse to the same present Frontier while retaining different owner-side continuation states.

## 6. S5C — quotient ladder and dynamic dependency

Across 102,919 unique generated histories, no observed violation was found for:

```text
equal ContinuationKernel => equal FrontierCore
equal FrontierCore       => equal ImmediateActionSignature
```

Observed unique representation counts:

```text
102,919 histories
→ 11,463 continuation kernels
→ 1,180 frontier cores
→ 159 immediate action signatures
```

The exact counts are generator-specific. The surviving architectural conclusion is not the ratios themselves but the refinement structure:

> There is no reason to demand one canonical representation serve history preservation, future transition, currentness recovery and immediate action equally well.

Dynamic commutativity sampling over 50,000 contexts / 120 sampled event-type pairs classified:

- 85 observed-always-commutative pairs;
- 30 context-dependent pairs;
- 5 observed-never-commutative pairs.

Examples of state-dependent dependency included election ↔ sanction, claim ↔ election, compromise-root ↔ election, and sanction ↔ control transfer/theft.

Candidate relation:

```text
a ⟂_s b
iff
continuation/currentness after a;b == after b;a at state s
```

Independence is therefore state-relative in the synthetic institutional semantics. Finite sampling does not establish universal commutativity laws.

## 7. S5D — consequence envelope

For the frozen immediate consequential-action rule, Binding Set could be quotiented again to a smaller `ConsequenceEnvelope`:

- possible consequential-authority statuses;
- possible office holders;
- possible effective controllers.

Across 100,000 synthetic partial-order batches:

- 2,061 unique Binding Sets;
- 133 unique Consequence Envelopes;
- no envelope→safe-action inconsistency found;
- no refinement-monotonicity violation found.

Two simple heuristics were falsified:

```text
MULTIPLE != HOLD
ONE      != ALLOW
```

For the frozen action:

```text
ALLOW
iff
all admissible bindings are AUTHORIZED
and all preserve the same office-holder/effective-controller principal.
```

This is immediate-action semantics only, not future-transition sufficiency.

## 9. Canonical derived laws from this track

The track supports the following bounded cross-owner derived laws for this problem class:

1. `RawHistory != ActionableCurrentness`.
2. Semantics-preserving history transformations should not alter a currentness-relative decision.
3. `AgentFacingCurrentness != OwnerTransitionState`.
4. Transition-state sufficiency is future-operation/query relative; do not centralize the experimental kernel.
5. `UniqueCurrentBinding != DeterminateFutureTransition`.
6. Partial-order uncertainty must remain set-valued until an admitted precedence relation legitimately refines it.
7. `OccurrenceOrder != ObservationOrder != AuthenticatedOrderEvidence != InstitutionalPrecedence`.
8. `Authenticated != Authoritative`.
9. `MULTIPLE != HOLD`; `ONE != ALLOW`.
10. Immediate consequence safety is a property of the admissible consequence envelope, not of uncertainty cardinality alone.
11. Institutional event independence/commutativity can be state-dependent.
12. Representation should be selected by decision horizon rather than maximized globally.
13. Forced linearization can create semantic safety errors by inventing a unique Now that the evidence does not support.
14. Raw partial-order exposure alone is not equivalent to a compiled set-valued currentness representation for finite Agents.

## 10. Owner disposition

No new AIC/Institution owner is admitted.

The experimental structures map back to existing responsibilities:

- Game / World: occurrence and continuing consequential world history;
- Security: exact control/compromise/authority-evidence/recovery state;
- Normative: constitutive/deontic/competence/valid-change semantics and admissibility of institutional precedence where its current policy says so;
- Interlocus: claim/binding/currentness/evidence-frontier/migration/conflict-preserving projection discipline;
- Computing: cross-owner experiment, abstraction/refinement/falsification and derived-law synthesis only;
- Harness: fresh-Agent execution apparatus, not semantic truth.

A `ContinuationKernel` implementation as a central persistent object is explicitly **not** earned. If future consumers need a continuation surface, prefer query-relative assembly from exact owner-native state and source-fenced projections.

## 11. Evidence-ladder disposition

This Track J3 does **not** establish COJC evidence level `J3 higher-order irreducibility` because all feasible proper subsets of Game × Security × Normative were not naturally intervened under one frozen owner-native target predicate.

It also does not establish J4 emergence or J5 phase transition.

What is established is:

- strong bounded representation-consumption evidence;
- deterministic currentness/transition/partial-order falsification evidence;
- one pre-registered `LINEARIZATION_COLLAPSE_HARM` result;
- a set of bounded cross-owner derived laws worth transferring to other consumers.

The next promotion test should therefore be **transfer**, not more ontology inside this synthetic world.

## 12. Reopen conditions

Reopen AIC-specific research when at least one of the following occurs:

1. a materially different consumer (Finance, Web, Security live workflow, Host continuity, collaborative Game, etc.) naturally encounters non-total currentness and reproduces/falsifies these laws;
2. an existing owner cannot answer a real future-operation query without manually reconstructing another owner's latent state;
3. Binding Set / Consequence Envelope fails on a new institutional action class that requires additional current consequence dimensions;
4. an admitted order witness creates a cross-owner precedence conflict that current Normative/Interlocus interfaces cannot represent;
5. a natural owner-subset factorial becomes possible, enabling a real higher-order irreducibility test.

Do not reopen merely to increase synthetic complexity.
