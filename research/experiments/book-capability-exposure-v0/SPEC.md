# Book Capability Exposure Falsifier v0

Status: preregistered experimental apparatus. No Media/Book mutation is admitted by this specification.

## Question

Can a representation-only change improve recovery of already-earned Ordivon capabilities without degrading anti-collapse distinctions, owner/authority boundaries, maturity calibration, or action selection?

## Frozen arms

- `BASELINE`: exact current seven-chapter Book bytes.
- `REORDER`: exact same chapter prose; for Chapters 2-7 only, the final `这一章没有证明什么` block is moved immediately before the chapter's existing final constructive/minimal-model block. No prose is added or deleted.
- `GESTALT`: `REORDER` plus one short chapter-end capability gestalt assembled only from claims already recoverable from that chapter. It adds organization/salience, not new owner facts or stronger standing.

All arms use the same fresh Provider/model, zero-Tool surface, result schema, case order and budgets.

## Outcomes

D — distinction retention / anti-collapse.
O — owner and authority correctness.
C — capability recovery.
R — realization/maturity calibration.
A — action/reachability selection.
K — context/token cost.

A treatment is not admitted merely because C improves. It must preserve D/O/R and must not create false capability promotion on the proposal-only negative control.

## Interpretation ceiling

This experiment can establish an Agent/model/operation-specific representation effect. It cannot establish Human reading benefit, universal writing law, or a global capability-exposure schema.
