# J0 — Joint Capability Measurement Calibration and Natural-Candidate Tournament

Status: **ACTIVE / contract frozen for first execution**.

J0 exists to calibrate the Cross-Owner Joint Capability programme before it is allowed to use stronger language such as emergence.

## Questions

1. Can the method correctly identify a known scoped positive interaction (PAL F12)?
2. Can it correctly reject a tempting but non-identifiable interaction (PAL F15)?
3. Which current cross-owner candidates expose a real natural target whose proper-subset interventions are feasible without manufacturing failure?
4. Does any candidate justify a J1/J2 experiment with a frozen owner-native outcome and a non-tautological joint hypothesis?

## Calibration controls

### Positive

`../pal-foundations-v0/f12-results-v0.json`

Expected classification: `SCOPED_COMPLEMENTARITY`, not emergence.

### Negative

`../pal-foundations-v0/f15-disposition-v0.json`

Expected classification: `NONIDENTIFIABLE_CURRENT_WORLD`, because ambient transport already provides the target outcome.

## Candidate tournament rules

A candidate must name:

- natural consumer/workload;
- exact target transition or decision;
- owner-native outcome authority;
- candidate owner factors;
- why each factor is independently owned;
- feasible treatment subsets;
- strongest simple baseline;
- risk/authority ceiling;
- why joint success is not merely definitionally implied;
- holdout/transfer route if the first interaction is positive.

Reject the candidate before execution when:

- the missing baseline has to be manufactured;
- a factor is only another name for the target predicate;
- owner truth would have to be copied into Computing to run the test;
- no proper-subset intervention is feasible or interpretable;
- the outcome depends only on a scalar score invented by the experiment;
- a simpler owner-local consumer/deletion audit already answers the question.

## Initial candidate families

1. `SCD × Computational Possibility` — representation-sensitive possibility.
2. `Interlocus × Security × World` — adversarial rebinding/continuation.
3. `Media × SCD × Harness` — observer-relative representation and effective Agent capability.
4. `Game × Security × Normative` — authoritative adversarial institutional world.
5. `Finance × Interlocus/Workstation × World × CP` — resilient read-only capital-world capability.

J0 does not force one winner. The first candidate with the cleanest natural identifiability should win.

## Outputs

- a classification receipt for F12 and F15;
- a current candidate matrix with `REJECT / HOLD / ADMIT_NEXT_EXPERIMENT` dispositions;
- one frozen J1/J2 contract only if admission conditions are met;
- compact negative records for rejected candidates.

## Stop rule

If no current candidate is naturally identifiable, J0 closes with `NO_CURRENT_JOINT_EXPERIMENT` and the programme waits for a real consumer pressure. That is a successful result.
