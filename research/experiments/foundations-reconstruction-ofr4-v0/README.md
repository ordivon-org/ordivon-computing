# OFR4 — Theory Unit Compression / Causal Reconstructability

OFR4 compares frozen Agent-facing representations derived from OFR3. It does not define a product schema, service, registry, or Core/Knowledge promotion.

The four development stress cases are Runtime, Host, Human, and Web. The six holdout cases are Harness, World, Finance, Workstation, Security, and Game. Treatment semantics, reopen probes, oracles, and scoring gates are frozen before live Provider execution.

The primary objective is causal reconstructability per generation-context cost, with unsupported inference and over-generalization treated as failures rather than rewarding fluent guessing.
