# HD0 — Industrial-to-Agent Historical Theory Dogfood

HD0 designs a 250-year out-of-domain historical test of Ordivon's current RSI/world-model priors.

The main study window runs from the First Industrial Revolution to 2026. The unit is not an inventor name or one patent date. It is an **innovation/discovery trajectory**:

```text
pressure / anomaly / opportunity
→ available world model and competing routes
→ observation / instrument / hypothesis / prototype
→ falsification or decisive validation
→ enabling complements and constraints
→ diffusion / standardization / scaling
→ externalities / failures / revisions
→ second-order capability and research effects
```

The campaign is explicitly designed against winner's-history bias, Nobel/patent bias, hero-inventor stories, Western-only sampling and retrospective causality.

LW0 motifs and anti-laws are frozen before bulk collection. Source collectors record source-native facts first. Structural coding happens only after a trajectory evidence bundle is locked.

Main target: **320 trajectories across eight epochs**. A 96-case Anchor subset receives deep evidence bundles; 32 of those are additionally used for de-identified historical prospective replay.
