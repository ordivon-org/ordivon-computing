## Semantic decision

For each case the auditor chooses one bounded next causal research target:

- `repeated-low-information-failure`
- `information-route-bottleneck`
- `survival-spatial-pressure`
- `local-policy-choice`
- `world-mechanic-affordance`
- `mixed-or-insufficient-evidence`

The labels are research targets, not claims that one scalar score defines Game quality.

## Comparators

### Full evidence

The auditor sees all six Turn windows. Three independent same-model submissions establish a full-evidence reference. A case is `stable-reference` only when at least two of three select the same target. Cases with three-way disagreement remain semantic ambiguity evidence and are excluded from agreement-rate denominators rather than forced into a gold label.

### Progressive stopping

The auditor starts from a compact mechanical overview plus only an inventory of Turn identities/highlight reasons. It may request one or more exact Turn windows. After each batch it must either:

- request a Turn and explain what live alternative that Turn could discriminate; or
- STOP with a research target, live alternatives, and a statement that no remaining available window is expected to change the target.

No confidence threshold is available.

After STOP, RF1 performs a hidden counterfactual full reveal under the same decision task. A changed target is a `false early stop`.

### Matched random

A frozen random seed selects exactly the same number of **unique** Turn windows consumed by the progressive trial for that case. The auditor then makes one decision. This tests whether progressive selection adds value beyond merely reading less.

## Primary measures

- stable-reference agreement;
- false-early-stop rate;
- unique windows observed / six;
- redundant observation requests;
- mechanically tagged event-class coverage;
- source/context bytes;
- Provider tokens and calls;
- wall time;
- matched-random agreement at the same unique-window count.

RF1 does not modify Game product code or promote a universal stopping mechanism. The outcome may support, narrow, or falsify the Research Frontier Model stopping hypothesis.
