# RF1 — Marginal Evidence Value / Stopping Report

## Question

Can a Game auditor save evidence by repeatedly deciding whether another causal window could still change its bounded research target?

RF1 prospectively tested this after RF0 froze `RF1-GAME-STOPPING-001`. The ResearchBet remained shadow-only and was never supplied to the evaluated model.

## Input correction before accepted trials

The originally predeclared two seed strings generated byte-identical trajectories except for seed provenance fields. Treating them as independent cases would have manufactured replication.

Before any accepted semantic Provider trial, RF1 therefore replaced the duplicate second seed with a materially different Game variant under the same Experience World Model packet protocol:

- `269d8cf...` — before AF Loop 001 product mutation;
- `6bc7405...` — after AF Loop 001.

This preserved eight cases: two Game variants × four existing strategy probes.

## Reference quality

Full-evidence reference was unusually stable:

```text
8 / 8 cases had unanimous 3 / 3 same-model references
```

Reference targets were:

```text

2 × repeated-low-information-failure
```

The two `repeated-low-information-failure` references were both `hive-hunt`, matching the owner pressure that Hive-hunt is the highest-failure probe and may contain repeated low-information failure.

## Primary result: the Agent never stopped early

The predeclared prediction required mean unique-window consumption below 75% of the six-Turn trajectory.

Observed:

```text
mean unique-window fraction = 1.00
forced by evidence exhaustion = 8 / 8
self-initiated early stops = 0 / 8
```

Every progressive trial consumed all six Turn windows. Most requested them as three two-window batches:

```text
0,1 → 2,3 → 4,5
```

One case varied the final ordering but still consumed all six.

Therefore RF1 does **not** estimate a meaningful false-early-stop rate. No autonomous early stopping occurred. The stored aggregate `falseEarlyStopRate=0.0` is a mechanical consequence of zero early-stop opportunities and must not be interpreted as stopping success.

## Decision quality

Even after consuming all evidence, the iterative progressive path agreed with the unanimous full-evidence reference on only:

```text
6 / 8 = 75%
```

Both disagreements were Hive-hunt cases.

The matched-random comparator received the same number of unique windows. Because progressive always consumed six windows, matched-random degenerated into a one-shot full-evidence comparator and agreed:

```text
8 / 8 = 100%
```

This does **not** prove random low-budget selection is superior: there was no reduced budget to compare. It does prove that the adaptive progressive loop produced no evidence savings and did not dominate a much simpler one-shot read of the same six windows.


Post-AF-loop Hive-hunt:

```text
3/3 full reference    → repeated-low-information-failure
progressive after 6/6 → survival-spatial-pressure
matched full one-shot → repeated-low-information-failure
```

The counterfactual reveal label in RF1 v1 included the stopped target string and can therefore anchor that reveal call. Because no trial actually stopped early, RF1 does not use reveal calls as primary evidence. The independent 3× full references plus matched one-shot comparator are sufficient to establish both progressive disagreements.

The important result is:

> serial meta-deliberation over evidence acquisition can change the final semantic decision even when the eventual evidence set is complete.

## Falsification verdict

The RF0 bet predicted:

- `<0.75` mean unique-window fraction;
- actual decision stability on most stable-reference cases;
- progressive agreement at least as good as matched random at the same window count.

Observed:

- `1.00` mean unique-window fraction;
- `8/8` evidence-exhaustion stops;
- `6/8` progressive agreement;
- `8/8` matched full one-shot agreement;
- materially higher Provider-call, token, and wall-time cost.

Therefore the tested operator is **falsified**.

## World-model update

RF1 does not falsify stopping as an RSI requirement. It falsifies one operational form:

```text
serially ask the same Agent whether another observation might still matter
```

on a small finite six-window evidence universe.

A new tractability variable is now explicit:

> **adaptive-selection overhead** — the cost and semantic path dependence introduced by deciding what evidence to inspect can exceed the cost of simply inspecting a small bounded evidence universe once.

Thus:

```text
adaptive evidence selection
!=
cheaper research
```

and:

```text
complete evidence set
!=
path-independent semantic conclusion
```

For small finite evidence universes, a strong one-shot full-evidence baseline is not a naive baseline; it may be the tractable operator.

## Game-local conclusion

RF1 does not justify changing Game product code or the Experience World Model packet selector. The existing selector being broad on six-Turn profiles is real, but this experiment shows that replacing it with a serial Agent-controlled STOP loop would be worse.

The next Game perception improvement, if pursued by the Game owner, should therefore be tested against the cheap full-trajectory baseline and should not inherit RF1's serial stopping protocol by default.

## Research-frontier conclusion

Research taste must model not only evidence value, but **the overhead of choosing evidence** relative to the size/cost of the evidence universe.

The remaining stopping problem is narrower:

> Can marginal evidence value be estimated without paying one serial model-decision round per observation, and can a stopping rule preserve semantic decisions on evidence spaces large enough that full inspection is genuinely expensive?

That question is not automatically admitted as another experiment here.
