# EDA Probe Generation Compiler v0.1

Consumes provider-observed mutations from a declared bounded mutation grammar and compiles discriminator standing for two explicit schematic-contract hypotheses.

Responsibilities:
- filter to admitted mutation kinds;
- determine which provider-observed consequences separate the current hypotheses;
- compare candidates by responsibility projection rather than source identity;
- deterministically select one representative only when all generated discriminators are outcome-equivalent and equal-cost;
- report `no_discriminator_in_generation_basis` when the current grammar cannot produce a separator.

Absence is deliberately scoped: it means the declared generation basis was insufficient. It never claims that no possible experiment exists.
