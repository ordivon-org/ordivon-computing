The evidence packet will be frozen from current Computing owner artifacts, not synthetic cases. Candidate families include:

- Book Result/Value compression falsifier — completed negative admission plus bounded exploratory reconstruction value;
- Owner-pressure discovery — completed negative selector result with no new architecture;
- Skill compilation — completed candidate rejection despite earlier development advantage;
- Experiment Loop — bounded cross-evidence self-improvement evidence with explicit non-open-ended ceiling;
- P0 consumer falsification — bounded measured cognition/authority-timing improvements;
- Crosscut-maintenance P5 — completed contraction with measured local cost reductions but conservative attribution boundary.

The oracle must be derived before model runs from explicit owner text and kept narrower than any unsupported benefit/optimality claim.

This track is the natural-operation test: the map is admitted only if it improves an actual result-audit operation enough to justify operation-relative exposure.
