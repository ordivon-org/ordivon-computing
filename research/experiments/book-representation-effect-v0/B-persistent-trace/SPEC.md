# B — Persistent-trace recovery under intervening context

Question: when the full reference is no longer present, does explicit representation at acquisition time produce a better bounded durable trace for later recovery?

This is not biological memory and not literal wall-clock delay. It isolates two mechanisms relevant to Agent environments:

```text
source representation
→ finite trace compression
→ source removed
→ unrelated intervening context
→ fresh consumer recovery
```

Arms:

- `BOOK_TRACE`: acquisition Agent sees only the exact five-chapter Book;
- `MAP_BOOK_TRACE`: acquisition Agent sees compact Result/Value map followed by the same Book.

Acquisition Agents do **not** see test cases. Each must emit one bounded recovery note for a future research-result audit. Recovery notes are frozen before recovery runs.

Recovery consumers receive only:

1. the frozen recovery note;
2. one frozen unrelated current Ordivon Computing lineage text as intervening-context interference;
3. the exact eight multi-label composite cases from the prior experiment.

Primary outcome: complete relation-reconstruction label errors and exact cases. Secondary outcome: trace bytes/tokens and systematic error classes.

Admission rule: a map-derived trace earns persistent representation value only if recovery improves across independently generated traces without merely carrying a materially larger trace. No Media/default-context consequence follows automatically.
