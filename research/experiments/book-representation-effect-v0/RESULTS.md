# Book Representation Effect v0 — Results

Status: completed current system-level programme phase. **No Media Book mutation, Chapter 6, universal Result taxonomy injection, Human learning mechanism or new context service is admitted.**

## 1. Question

Prior Book work established two facts that initially looked contradictory:

```text
A strong fresh Agent can often generate missing distinctions from the five-chapter Book.

A richer explicit Result/Value map can still reduce relation-reconstruction errors in one bounded operation.
```

This programme asks a more appropriate question:

```text
RepresentationEffect
= f(consumer, operation, capability/model variant, persistence path, interference, consequence)
```

Four pressures were pursued:

A. provider/model-variant sensitivity;
B. persistent recovery after bounded trace compression and intervening context;
C. a natural current Computing Result audit;
D. Human evidence transport and residual-study admission.

## 3. Track B — immediate reconstruction value does not transport to bounded persistent traces

A separate recovery apparatus was constructed:

```text
full source representation
→ acquisition Agent
→ exactly 2200 UTF-8-byte durable trace
→ original Book/map removed
→ 32,182-byte unrelated current Computing lineage
→ fresh recovery Agent
→ same eight composite cases
```

The unrelated lineage is `COMPUTER-AGENT-NATIVE-LINEAGE-20260724-20260825.md`, SHA-256 `b0848f8c...`.

Acquisition Agents never saw the cases. All six final traces were normalized to exactly 2200 bytes. The final acquisition prompt explicitly stated that only the first 2200 bytes would survive, making the experiment one of deliberate prefix-priority compression rather than hidden truncation. The Provider nevertheless reached its output ceiling, so this is a bounded apparatus rather than a general memory law.

Recovery result:

A simple retained-prefix diagnostic shows why a timescale interaction is plausible. Across the three Book traces, the first 2200 bytes heavily preserve `Standing`, `Authority`, `Currentness`, `Representation` and consequence controls. Map+Book traces use substantially more of the same fixed budget naming `Improvement`, `Value`, `Consumption`, `Benefit` and related taxonomy. Future recovery then over-projects several of these relations.

This supports a bounded new distinction:

```text
RepresentationThatHelpsImmediateReconstruction
!=
RepresentationThatProducesTheBestPersistentTrace
```

It does not prove that explicit maps generally damage memory; trace budget, acquisition policy, model and intervening context are moderators.

### Carrier history

Several pre-semantic acquisition carriers were rejected rather than counted:

- too-small aggregate Harness budget caused zero-provider-call `budget_exhausted` runs;
- long structured conclusion notes hit a DeepSeek/Harness finish-reason mismatch;
- long JSON-wrapper notes could be truncated before JSON closure;
- a plain-text attempt without explicit persistence budget was cancelled because blind truncation would confound compression with position.

The final carrier uses the same authenticated DeepSeek Chat transport as Harness, `deepseek-v4-flash`, thinking disabled, plain note text and mechanical equal-byte normalization. Recovery itself remains ordinary fresh Harness Agent Runs.

## 4. Track C — natural Result audit is limited by evidence geometry more than taxonomy

A 29,020-byte current Computing owner packet was frozen from six real experiments:

- Result/Value Book falsifier (`RV`);
- owner-pressure discovery (`OPD`);
- Skill compilation (`SKILL`);
- Continuous Experiment Loop (`CEL`);
- P0 consumer falsification (`P0`);
- P5 crosscut contraction (`P5`).

Each artifact was audited across five relations: ObjectiveAchievement, BoundedImprovement, CurrentConsumption, RealizedBenefit and BroaderPromotion.

### Predeclared raw oracle result

| Representation | Correct judgments | Mean prompt tokens |
| --- | ---: | ---: |
| Book + full owner packet | 73 / 90 | 27,869 |
| Map + Book + full packet | 72 / 90 | 28,645 |
| Book + operation-relative evidence cards | **77 / 90** | **23,218** |
| Map + Book + cards *(post-result exploratory)* | 67 / 90 | 23,993 |

The generic taxonomy does not improve the natural full-source audit. Evidence cards improve raw accuracy modestly while removing about 4,651 prompt tokens (about 16.7%) versus full source. Adding the taxonomy back on top of the cards substantially degrades this workload.

### Oracle-boundary challenge

After seeing the results, three predeclared positive fields were judged too strong under the compact map's own evidence requirements:

- `CEL.currentConsumption`;
- `P5.currentConsumption`;
- `P5.realizedBenefit`.

`policy promoted`, `resulting method exists`, or `physical contraction occurred` directly establish materialization/change, but do not automatically establish a named downstream consumer/use contract. P5's local cost reductions are real measured consequences, but the beneficiary/benefit relation is less explicit than the predeclared oracle assumed.

The original oracle is retained unchanged. There is **no silent rescore**. A sensitivity view excluding those three challenged judgments yields:

| Representation | Source-robust sensitivity score |
| --- | ---: |
| Book + full packet | 73 / 81 |
| Map + Book + full packet | 72 / 81 |
| Book + evidence cards | **76 / 81** |
| Map + Book + cards | 67 / 81 |

The robust conclusion is therefore narrower than “cards solve Result audit”:

```text
Generic taxonomy is not the missing natural-operation representation.
Operation-relative evidence projection is cheaper and modestly better in this packet.
Taxonomy + evidence projection is not automatically additive.
```

One cards replicate simultaneously missed `ObjectiveAchievement` for RV/OPD/SKILL. Those are all negative/rejection results whose research objective nevertheless closed. The cards strengthened evidence but did not explicitly preserve the declared target/claim. This independently converges with current Human C1 research that contracts review packets to `Claim | Evidence | Challenge` with Boundary supplied by context: evidence-only projection can lose the target needed to judge achievement.

This is retained as a **next falsifier**, not repaired post hoc in this experiment.

## 5. Track D — Human evidence is transport-gated, not simulated

Current Human authority `research/agentic-capability/EVIDENCE-TRANSPORT.md` requires:

```text
external Human evidence
→ mechanism/moderator boundary
→ Ordivon structural transport analysis
→ natural Ordivon dogfood
→ bounded residual Human experiment only if decision-relevant uncertainty remains
```

The Representation Effect Agent/system experiments above are the system-falsification stage. They make direct Human extrapolation less defensible, not more: representation effects vary by model variant, operation and persistence path.

`D-human-protocol/PROTOCOL-DRAFT.md` has therefore been converted from an immediate A/B plan into a transport gate plus natural-dogfood protocol. A residual Human comparison remains specified only as a dormant instrument if competing policies survive transport.

No LLM persona is treated as Human evidence. No Human comprehension, retention, transfer or learning claim is made.

## 6. Unified standing

The programme rejects a one-dimensional `more explicit = better` model.

Current evidence instead supports:

```text
RepresentationEffect
= f(
    consumer/model variant,
    operation,
    source search geometry,
    persistence budget,
    interference path,
    target relation,
    consequence
  )
```

More specifically:

1. **Generative Book core remains valuable.** Strong immediate decisions often need no extra taxonomy.
2. **Explicit maps can help dense relation reconstruction.** The effect can be large for one model variant and modest for another.
3. **What helps now may hurt what gets sedimented.** Under a fixed 2200-byte trace, taxonomy-heavy acquisition produced no exact recovery gain and more label errors.
4. **Natural work is often evidence-search limited.** Source projection outperformed taxonomy injection in the frozen Computing audit while using less context.
5. **Representation composition is non-monotonic.** `Map + cards` performed worse than cards alone.
6. **Oracle quality remains independently challengeable.** Representation experiments do not grant the evaluator immunity from source/evidence requirements.
7. **Human transport is a distinct problem.** System results choose what is worth natural dogfood; they do not substitute for Human outcome evidence.

## 7. Engineering / Book destination

No new universal mechanism is earned.

```text
Media five-chapter Book core       = NO_CHANGE
Chapter 6                           = NOT_ADMITTED
Global Result/Value injection       = NOT_ADMITTED
Global evidence-card service        = NOT_ADMITTED
Operation-relative source projection = RETAIN AS DESIGN PRESSURE
Result map                           = RETAIN AS OPERATION-SPECIFIC AID
Persistent default trace of map      = NOT_ADMITTED
Human direct A/B                     = DORMANT / TRANSPORT-GATED
```

The strongest forward hypothesis is not “add the map.” It is:

> For operations that require auditing many orthogonal relations, compile the smallest source-bound `target/claim + evidence + challenge + boundary` view that preserves the distinctions required by the current consumer, rather than globally injecting a richer ontology.

That hypothesis must be tested in a later natural workload; this programme does not create a new packet schema or service.

## 8. Reopen conditions

Reopen Book/default representation only if one of the following is reproduced:

- a named ordinary consumer repeatedly fails without an explicit representation and succeeds with it at justified net cost;
- a lower-resource or materially different consumer demonstrates a stable deficit that the representation repairs;
- delayed/natural recovery shows a representation survives compression/interference better rather than merely improving immediate output;
- Human natural dogfood leaves a decision-changing transport gap;
- a source-bound operation projection demonstrates enough repeated value to justify environmentalization rather than ad hoc compilation.

Otherwise `NO_CHANGE` is the mature result.
