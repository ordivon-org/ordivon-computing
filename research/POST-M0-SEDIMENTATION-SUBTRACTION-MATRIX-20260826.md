## 3. Candidate A subtraction

### What existing M0 already explains

Existing M0 can explain that:

- a standing should not be prematurely promoted (`M04`);
- a historical standing may become stale/currently irrelevant (`M07`);
- research truth does not authorize engineering/effects (`M08`);
- the representation/problem frame may itself need repair (`M02`);
- preserved material may still be undiscoverable (`F07`).

### What disappears without Candidate A

Those mechanisms do **not** name or directly represent the following transition:

```text
validated/current standing
+
concrete future consumer
+
repeated reconstruction burden / consequence
→
selective change to the consumer's starting conditions
(default / routine / semantic surface / guard / Tool visibility / first-look / responsibility placement)
→
future behavior changes before the consumer re-derives the standing
```

Nor do they directly represent the inverse decision:

```text
correct/reusable standing
→ KEEP EXPLICIT / KNOWLEDGE ONLY / NO_DEFAULT
```

`M04 Promotion` is insufficient because a standing can be highly promoted/canonical and still correctly remain out of a default consumer environment. `M08 Consumption` is insufficient because environmentalization may be a read-only representation/default/routine change with no external effect authority. `M07` is insufficient because currentness/recovery can be perfect while the relevant standing remains absent from ordinary starting conditions. `F07` is insufficient because discoverability can succeed while repeated consumer reconstruction remains expensive.

The deletion-positive residual is therefore **consumer-relative constitutive placement**: the research process sometimes changes not only what is known, but the default conditions under which later research/operation begins.

### Positive causal witness

ACS9 is the strongest positive control because it includes:

```text
same underlying owner capability
+ pre-implementation raw/compiled comparison
+ real owner surface/default changes
+ post-implementation fresh consumers
+ direct wrong-wrapper/conformance checks
```

This is stronger than a Book/document example and establishes a bounded future-consumer consequence.

### Negative controls

- Host/World/Game in ACS9 were left unchanged where no projection was earned.
- Pressure-selection guide was withheld despite being semantically correct because RAW already reached 20/20 and the guide cost +30.9% tokens.
- Chapter 5 explicitly supports `Knowledge + NO_DEFAULT` for niche standings.

These controls show the mechanism is **selective**, not a universal drive toward deeper materialization.

### External subtraction

Organizational memory/learning, routines, infrastructure-in-practice, distributed cognition and function-allocation/automation theory already own the broad facts that knowledge can become routine/environment and that automation/roles reshape practice. Ordivon does not own those discoveries.

The narrow M0 observation is only that Ordivon's current research ecology repeatedly uses **challengeable consumer-relative environmentalization** as a transition between typed standing and future operation, under owner/currentness/authority boundaries and with `NO_DEFAULT` as a valid result.

### Candidate A disposition

**Provisional: `NEW_M0_MECHANISM`**, subject to one final representation/additivity falsifier against current M0. The evidence criteria 1–3, 5–6 are already met; criterion 4 (existing-M0 residual) is strong by deterministic subtraction but deserves an independent fresh-consumer check before Atlas mutation.
