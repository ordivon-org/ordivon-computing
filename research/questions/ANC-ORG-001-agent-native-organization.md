# ANC-ORG-001 — Agent-Native Organization

## Question

How should a person, multiple models, Tools, and persistent project state coordinate around long-running Goals without making conversation history or fixed roles the primary organizational structure?

## Current hypothesis

An Agent-native collaboration system can organize around five planes:

```text
Goal
Capability
Execution
Knowledge
Feedback
```

The shared operational objects are Goals, Tasks, Attempts, Workspaces, Artifacts, Facts, and Task Capsules. People provide direction, value judgments, and responsibility for consequences. Models and Runtimes provide exploration, execution, observation, and continuity.

## First experiment

Use one real project Goal with several genuinely independent branches:

- code or architecture inspection;
- empirical test execution;
- literature or external-system research;
- synthesis and integration.

Run the branches through separate Workspaces or Agents and join them through Artifacts rather than copied conversation histories.

## Evidence

- useful parallel progress rather than duplicated work;
- low-cost handoff through Task Capsules;
- clear state after one Agent is replaced;
- successful artifact-based join;
- human ability to understand and redirect the Goal from the persistent workspace view.
