# ANC-SECURITY-001 — Full-Spectrum Adversarial Agent Systems

## Question

How can Ordivon elicit and measure the maximum credible attack, defense, adaptation, coordination, and recovery capabilities of Agent systems inside dynamic owned ranges while independently limiting and verifying real-world consequences?

## Why this belongs in Ordivon Computing

The problem crosses model cognition, Host state, Runtime execution, Link connectivity, Edge bodies, Game simulation, Security evaluation, evidence, and organizational authority. No product repository can define the shared identities or validity criteria alone.

## Current hypothesis

The central abstraction is a pair of orthogonal envelopes:

```text
Capability Envelope
  model + Harness + tools + memory + compute + time + actors

Consequence Envelope
  worlds + targets + identities + resources + external boundaries
```

A credible experiment maximizes the first within the declared research question and independently constrains, observes, and audits the second.

## First evidence program

1. Define one Campaign Manifest and one World identity shared across Host, Link, Edge, Runtime, Game, and Security.
2. Construct a disconnected dynamic range with at least three services, one disposable Edge node, one Red Agent, one Blue Agent, and an independent observer.
3. Inject topology and service changes during the campaign.
4. Permit tool construction, persistent range-local state, and multi-stage planning.
5. Freeze, export, reset, and replay the campaign.
6. Compare at least two Harness or Tool configurations without changing the Consequence Envelope.
7. Preserve escape attempts, observer loss, invalid runs, and negative results as first-class outcomes.

## Evidence required

- exact model, Host, Tool, budget, network world, Edge node, and source identities;
- independent network and execution event roots;
- reproducible baseline construction and destruction receipts;
- one adaptive Red or Blue trajectory that cannot be reduced to a fixed answer script;
- evidence that changing Capability Envelope inputs changes measured behavior;
- evidence that undeclared external effects are absent or explicitly classified as containment failure;
- replay or causal reconstruction sufficient to explain decisive actions and failures.

## Non-goals

This question does not authorize activity against unrelated real systems, treat public reachability as permission, or replace mature operating systems, hypervisors, network emulators, scanners, browsers, or security tools. Ordivon should compose those systems and own Agent, campaign, evidence, consequence, and recovery semantics.
