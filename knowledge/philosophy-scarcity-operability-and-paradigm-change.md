# Scarcity, Operability, and Paradigm Change

A participant never acts on the complete structure of reality. It acts on distinctions that its current capabilities can observe, retain, evaluate, influence, and recover from.

This produces a general relationship:

```text
available capability
→ operational distinctions
→ usable world model
→ locally rational structures
```

When capability changes, the useful world model can change with it.

## 1. Operational resolution

Two states may differ in reality but remain equivalent for a participant when no available observation or action can distinguish them consequentially. New instruments, computation, memory, coordination, or recovery can refine that equivalence and expose a previously compressed dimension.

Examples include:

- microscopy turning microorganisms into actionable medical variables;
- version control separating experimentation from permanent loss;
- Agent Harnesses separating model weights from retained state, Tool use, and long-horizon behavior;
- formal proof systems separating logical validity from persuasive mathematical prose;
- durable Task state separating continuing work from one transient Session.

The tool does not necessarily create the structure. It makes the distinction operational at sustainable cost.

## 2. Scarcity shapes institutions and concepts

A recurring path is:

```text
scarcity or expensive failure
→ adaptation
→ institution and professional norm
→ norm treated as universal
→ original cost changes
```

This explains why many structures are locally rational without being timeless:

- information scarcity favored memorization and centralized access;
- implementation scarcity favored heavy pre-planning and code preservation;
- coordination scarcity favored fixed hierarchy and compressed reporting;
- high reconstruction cost favored prevention over experimentation and recovery;
- limited cognitive bandwidth favored linear plans over persistent branch graphs.

When the underlying cost changes, the structure becomes a conditional tool that must justify itself again.

## 3. Capability can separate old couplings

Scarcity often forces several functions into one object:

```text
knowledge ≈ memory
research ≈ paper
implementation ≈ durable asset
safety ≈ prohibition
model ≈ observed Agent capability
```

New control surfaces can separate them:

```text
knowledge access / source judgment / application
research state / publication / proof / experiment
replaceable code / retained judgment / stable contract
reversible exploration / external commitment / recovery
model / Harness / state / Tools / evaluator / environment
```

This decomposition is justified when the parts can fail, vary, or be evaluated independently.

## 4. Bottlenecks migrate

Lowering one cost exposes another.

When candidate generation and implementation become cheap, scarcity moves toward:

- validation;
- problem selection;
- attention;
- world access;
- experiment capacity;
- attribution;
- integration;
- long-term stewardship;
- responsibility for irreversible consequences.

The correct response is not to recreate the old scarcity. It is to organize around the new bottleneck while preserving cheap exploration.

## 5. Higher-dimensional representations

A higher-dimensional representation preserves distinctions that a lower-dimensional representation collapses:

```text
one next step        → Ready Frontier
success or failure   → trajectory, evidence, uncertainty, consequence
one paper            → claims, attempts, artifacts, counterexamples, open branches
one transcript       → replaceable cognition over durable Task state
allow or deny        → reversible interior and narrow commitment boundary
```

More dimensions are not automatically better. Each retained distinction must improve a decision, continuation, verification, or recovery enough to justify its maintenance cost.

## 6. Ordivon application

This lens explains the shared logic behind:

- **thin core** — do not freeze temporary scarcity into permanent responsibility;
- **high potential** — preserve freedom for capabilities and combinations that do not yet exist;
- **low governance** — persistent constraints must prove current net benefit;
- **high recoverability** — separate exploration from irreversible loss;
- **Ready Frontier** — represent real alternatives without pretending there is one universal next action;
- **evidence before admission** — generated output is not automatically accepted state;
- **replaceable cognition** — preserve Tasks, judgments, evidence, and commitments across Model and Harness replacement;
- **publication as projection** — articles and dashboards are views of deeper research and project state.

## 7. Two symmetric cautions

> Do not mistake a current scarcity condition for a fundamental law of the world.

> Do not mistake a local fall in cost for the disappearance of all constraints and consequences.
